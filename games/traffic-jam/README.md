# 塞車棋 · 50 關精確最短解

入口：`../traffic-jam.html`。原生 HTML / CSS / JavaScript；無外部依賴、網路請求、帳號或後端。

## 規則與操作

- 6 × 6 棋盤，車輛長度只能是 2 或 3 格；橫車只能水平滑動，直車只能垂直滑動
- 第 0 台是橫向 2 格紅車，固定第 3 列；紅車到達右端（左端座標 x=4）即成功駛入出口
- 不准重疊、跨越其他車、旋轉或越界；同一台車一次沿直線滑任意正整數格，算一步
- 點車，再點同方向空格，車頭／車尾滑到該格；鍵盤方向鍵或螢幕方向鈕每次滑一格
- Ctrl / ⌘ + Z 復原，H 提示，Esc 取消。完整解答可逐步或每 850ms 自動播放
- 自動儲存目前關卡、完整移動歷史、計時及已通關證明。讀取時重新從初盤重播，拒絕非法／被竄改的局面；完成記號也要有合法勝利歷史
- 所有手動移動皆可逆，因此已認證初盤的每個可達局面仍然可解。提示直接從目前局面做 BFS，不強制重開，不會以一個隨便的合法步驟假裝是解答

## 50 關並非換色或同盤重排

1. 固定種子 `0x52485336` / `1380471606` 的 C++ MT19937 建立候選車輛配置
2. 每個候選枚舉完整連通狀態圖。超過 180,000 狀態的候選整個捨棄，沒有拿截斷搜尋來宣稱最短解
3. 收集這個連通分量中「所有」紅車在出口的局面，做多源 BFS。因此每個狀態的距離等於到任一出口局面的真正最少滑動次數
4. 選該配置距離最遠的非勝利局面，保存下降至距離 0 的完整合法路徑
5. 車輛固定方向／車道／車長的多重集合不能重複；此外，獨立驗證比較「初盤全部矩形位置」，排除車輛 ID 或顏色置換，以及水平／垂直鏡射相同的題目
6. 接受 50 個配置，共考慮 3,455 個候選。每個難度區間取 10 關：8–11、12–15、16–19、20–24、25 以上，按最短解排序。最難一關為 44 步

`levels.json` 是權威資料，每關包含所有車輛、初始軸座標、完整解答、精確最短步數、候選序號及完整分量／目標數量。`levels.js` 只是相同資料的瀏覽器包裝，可直接以 file:// 開啟頁面而無須 fetch。

## 可重現生成

在此資料夾執行：

```sh
g++ -O3 -std=c++17 generate.cpp -o /tmp/traffic-generator
/tmp/traffic-generator /tmp/traffic-levels.json
cmp levels.json /tmp/traffic-levels.json
```

更新瀏覽器資料（只有實際更換關卡時才需要）：

```sh
python3 - <<'PY'
from pathlib import Path
p=Path('.')
p.joinpath('levels.js').write_text('/* Generated by generate.cpp; full exact shortest-slide witnesses. */\n(function(r){const d='+p.joinpath('levels.json').read_text().strip()+';if(typeof module==="object"&&module.exports)module.exports=d;else r.TRAFFIC_LEVELS=d;})(typeof self!=="undefined"?self:this);\n')
PY
```

## 驗證

```sh
python3 verify.py
node test.cjs
node test-ui.cjs
node --check app.js
```

- `verify.py`：獨立 Python 規則，逐格檢查初盤、每一步與終局；另從全部 50 個初盤獨立 BFS，確認解答真的是最短。也檢查 50 種配置與鏡射／重標籤去重。結果寫入 `verification.json`
- `test.cjs`：實際遊戲引擎重播 897 次滑動，91,440 次獨立「掃過格子」規則對照，50 次執行時 BFS 最短解確認，偏離路徑後可解性、可逆性、非法移動及存檔竄改檢查。結果寫入 `engine-test-report.json`
- `test-ui.cjs`：執行正式 UI 程式，以真實選車＋目的空格回呼完成全部 50 關；測 200 次連續復原、走偏提示、44 步示範、暫停／關閉／換關中斷、過期搜尋取消、存讀檔、假通關資料拒絕及 localStorage 不可用。這是 DOM 狀態測試，沒有宣稱完成真實瀏覽器的像素、觸控或視覺驗收

## 檔案

- `engine.js`：可重用純規則、合法移動、可分批 BFS、存檔驗證
- `app.js` / `style.css`：繁體中文介面、車輛 CSS 插畫、單畫面桌機／手機布局
- `generate.cpp`：可重現完整狀態圖生成器
- `levels.json` / `levels.js`：50 關與全部最短解證明
- `verify.py` / `test.cjs` / `test-ui.cjs`：獨立驗證和執行時／UI 測試

尺寸很矮的螢幕保留頁面捲動，避免把方向控制和狀態列裁掉。正常手機及桌機主畫面不需捲動。當前瀏覽器的儲存不跨裝置同步，清除網站資料會清除進度；本遊戲未安裝 Service Worker，不宣稱首次離線載入可用。
