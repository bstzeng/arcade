# 監視器迷陣

觀察鏡頭下一拍方向，利用控制台短暫關閉監視。

攝影機每拍轉向；紅色條紋為目前光束，移動後按新方向檢查。站在 H 可駭入，停機 3 拍。取得 ◇ 控制碼後到 E 控制室。移動、等待、駭入都會推進一拍。

100 個固定離散任務。每關資料在 levels.json，逐步勝利見證在 witnesses.json；levels.js 為瀏覽器無須網路請求的相同資料副本。共用引擎 ../stealth120-common/engine.js 中的 camera-labyrinth 分支是本遊戲的實際規則。

驗證：從 arcade 執行 node games/stealth120-common/verify.cjs。

提示、示範、撤銷與玩家完成分開；示範不增加完成數。正規規則的倒帶不是協助。所有動作離散進行，不使用真實時間。沒有外部服務、安裝套件或追蹤。
