# 押韻救援

補出符合情節、字數與韻腳的句尾，接續冒險詩。

## 玩法

補出冒險詩的句尾，同時符合情節、整句字數與韻部。採寬韻：an 含 ian／uan，ang 含 iang／uang，ao 含 iao，ou 含 iou，en 含 in，u 含 u；不評平仄。可用列出的同義詩句，非開放式詩歌評分。

100 個可直接選擇的關卡。操作、協助紀錄、詞彙範圍、AI 資訊邊界及驗證方式見 [家族說明](../words120-common/README.md)。
