# 潛行與諜報：十五款離散策略遊戲

15 款各有 100 個固定任務，共 1,500 關。HTML、CSS、JavaScript 與 SVG 全部本地載入，沒有套件或外部服務。這一批只擁有本資料夾、catalog.json 所列的十五個遊戲資料夾和同名 HTML 入口；不改既有遊戲或大廳。

## 確切承諾

- 每個 witnesses.json 都是對實際 engine.js 的合法動作序列，抵達公開勝利條件。
- verify.cjs 重播全部 1,500 序列，逐步檢查輸入不被修改、AI 位置／朝向／模式合法、搭檔移動合法，再以另外撰寫的目標判斷檢查勝利。不是解答唯一性證明。
- 100 個語意任務簽章排除 ID、生成重試次數及行動／氧氣／電量／限時數值，並正規化無序牆壁與設備清單。任務變化包括道路拓樸、門與壓板相對位置、目標位置、管口連線、照明和巡邏時序、材質與噪音、角色行程、文件條件、遮擋人群或設備座標。
- 反竊聽搜查另以板面尺寸與兩個設備座標作嚴格正規化，排除自動校準的環境噪音，並合併所有水平／垂直反射、轉置與等價頻道互換。生成器與驗證器共同拒絕這些操作後等價的關卡。
- 所有遊戲都是明確標示的回合制。思考不耗真實時間；每個有效動作才推進一拍。沒有真實時間反應容差或物理／真人對手必勝宣稱。
- 示範使用獨立狀態，沒有自動勝利按鈕。提示、觀看示範與撤銷會把目前嘗試標為協助；重開開始新的手動嘗試。已完成的手動紀錄不會被協助紀錄降級。
- localStorage 保存進度、關卡、協助標記與玩家動作歷史。重新載入用實際引擎重播歷史，不直接信任外部狀態快照。儲存不可用會在頁面說明。

## AI 是什麼

守衛只有位置、方向、視距、巡邏索引、警戒、最後目擊／聲源和搜尋計時。他們沿真正的可通行最短路調查；抵達後轉向搜尋，再返回巡邏。視線沿面朝方向延伸，牆遮擋。連續兩拍被看見或碰撞守衛失敗；離開視線會降警戒。誘敵布置的守衛目擊後仍守崗，只因聲源離崗，避免玩家把自己直接當免費誘餌。

人質只知道目前特工位置和公開守衛可見格，沿最短路跟隨，但不走進當拍可見格。目標、公眾、攝影機和文件巡檢員各有公開固定行程，非語言模型或隱藏隨機對手。身分門、通風管、雙區壓板與訊號題不需要虛構對手 AI；它們是確定規則的環境系統。

## 重現

在 arcade 目錄執行，使用 Node.js 18+：

```
node --check games/stealth120-common/engine.js
node --check games/stealth120-common/app.js
node games/stealth120-common/verify.cjs
```

重新生成全部資料：

```
node games/stealth120-common/generate.cjs
node games/stealth120-common/verify.cjs
```

可在 generate.cjs 後加一個或多個 canonical slug，只重新生成該遊戲。生成器採固定種子、實際引擎 BFS／帶啟發搜尋；兩款非路徑題使用完整合法的構造見證。它不參與玩家執行時所需資產。

## 驗證邊界

verification-report.json 綁定來源 SHA-256。控制器檢查以模擬 DOM 驗證示範分離、提示、撤銷、重開、選關、重複按鍵、失焦／離頁與儲存中斷，不冒充真實瀏覽器驗收。333px、400px、桌面視覺、觸控、直接網址與大廳整合由發布驗收另記。
