# 步步為營 Quoridor

## 遊玩與規則

以 HTTP 靜態伺服器開啟 `games/quoridor.html`。無套件／外部字型／網路 AI 依賴，不需要帳號。

標準 9 × 9 雙人規則。雙方各有 10 道牆，綠方前往最上列、橙方前往最下列。支援直跳，以及直跳被牆／邊界阻擋時的斜跳。牆不能交叉、重疊或封死任一玩家通往目標列的所有路線。先抵達目標列即勝；沒有任意回合上限和局。

- 同機雙人，或玩家一／玩家二與 AI 對弈
- 簡單、普通、困難三種難度；AI 皆在 Web Worker 計算
- 自動儲存、合法棋譜匯入／匯出、逐手回放、重開確認
- 悔一回合：AI 模式退回上一個人類回合；同機退回上一玩家回合。Quarto 的放置與交子合計同一玩家回合
- 鍵盤方向鍵與 Enter；Quoridor 在棋盤上按 R 旋轉牆
- 繁體中文介面、原創 CSS 棋子；桌面雙欄，窄螢幕垂直排版，棋盤保持方形

## AI

Quoridor 以最短路徑、圍牆延遲收益與對手反應評估；簡單在較佳動作間取樣，普通／困難用較深的 alpha-beta 搜尋。Quarto 會優先取勝、不主動送出立即必勝的棋子（存在安全棋子時），並用迭代加深與 alpha-beta 搜尋。困難增加搜尋深度與預算，不宣稱完美解或保證不敗。每個 worker 回覆都重新檢查合法性。重新開始、悔棋、回放、匯入與頁面離開會取消舊工作，晚到回覆不能改寫新棋局。

## 驗證

從專案根目錄執行：

```sh
node games/quoridor/rules-tests.cjs
node games/quoridor/controller-tests.cjs
```

規則測試涵蓋特殊規則、勝負／和局、AI 三難度合法性、存檔與悔棋。Controller 測試以 VM 載入真正的 app/ui 程式，涵蓋點擊流程、重開確認／取消、回放、重載、AI 鎖定、晚到回覆、錯誤復原與頁面生命週期；結果寫入 `verification.json`。這些是邏輯與 DOM 模擬驗證，不代表真實瀏覽器排版已驗證。

另提供 `node games/quoridor/browser-tests.cjs`（需要 Playwright 與 Chromium）驗證真實瀏覽器及 1440／768／390／320 寬度。此執行環境的 Chromium 啟動被 OS socket 權限阻擋，尚未完成此項測試；請查看彙整報告是否另有人工／雲端瀏覽器驗證。

此為完整雙人對局遊戲，沒有固定五十關要求或虛構關卡數。所有素材均為自製文字／CSS，沒有抓取商業棋盤圖像。
