This new-only family owns `games/path-lab/`, ten named game directories and their ten HTML entries. It does not change the historical 70 games, lobby or prior reports. No publication has been performed.

## Runtime

No packages, external APIs, fonts, backend or network requests. `levels.js` preloads all 100 starts and proofs; the page runs as a static offline asset. The common challenge shell owns local storage, undo/reset, level selection, assistance and isolated step replay. The new family app supplies game-specific grid, mirrored maps, rope, graph, staircase and metric-table renderers. Color is paired with text/symbols. Touch buttons and keyboard controls are supplied.

## Proofs

`games/<slug>/levels.json` contains exactly 100 levels and 100 proof objects. Every proof carries a start-state SHA-256, goal description, rules revision, action certificate and an explicit no-unique-solution declaration. All games use reachability evidence. Energy-network is intentionally a reachability model, with real resource and capacity constraints, rather than the planning manifest's provisional assignment profile.

- Euler witnesses are constructed with Hierholzer traversal and independently replayed edge by edge.
- Knight instances come from self-avoiding knight walks; an independent oracle checks exact knight geometry, coverage and no repeats.
- The six finite maze/resource variants and staircase puzzles are independently breadth-first searched.
- Tours are generated by complete permutation search. A separate Held–Karp implementation and shortest closed-walk Dijkstra, including arbitrary revisits, both check every optimum. Metric triangle inequalities are tested, avoiding the rounding-versus-shortest-walk trap.
- Engine object states and oracle array states are cross-checked on every witness step plus sampled reachable branches, covering tens of thousands of distinct states. This is exhaustive witness certification, not a claim to exhaust every game's entire state space.
- Canonical fingerprints remove rule-preserving relabelings/symmetries; equivalence tests transform all 1,000 levels. Decorative disconnected grid islands are removed.

## Commands (from the arcade directory)

- `node games/path-lab/verify-batch.cjs`: complete isolated offline batch, writes all final reports and exact SHA-256 source manifest.
- `node games/path-lab/boundaries.cjs`: rule fixtures, invalid actions and resource/geometry boundaries.
- `node games/path-lab/canonical.test.cjs`: 1,300 symmetry/relabeling checks.
- `node games/path-lab/app.test.cjs`: actual shipped app scripts under simulated DOM, all 1,000 level renders and interactive lifecycle flows.
- `node games/path-lab/verify.cjs`: all 1,000 proofs, independent transitions, game-specific feature gates, persistence/undo/replay and deterministic regeneration.
- `node games/<slug>/verify.cjs`: one title's corpus audit.
- `node games/<slug>/generate.cjs`: regenerate one title byte-equivalently.
- `node games/path-lab/generate.cjs`: regenerate the full fixed corpus.

`manifest.json` supplies exact Traditional Chinese discovery metadata. `batch-verification-report.json` is the isolated summary and full owned-source hash list. Each game has its own source-hashed `verification-report.json`. Runtime engine exports are createState, validateState, applyAction, inspect, legalActions and hint. All old files are outside this ownership set.

## Real browser gate: explicitly NOT RUN

The supplied build environment has already established cloud-browser localhost `ERR_BLOCKED` and denied local Chrome debugging socket access. Those blocked attempts were not repeated. Simulated DOM, source inspection and oracle checks do not certify rendered geometry, hit areas, font glyphs or actual browser APIs.

`browser-qa.cjs` is prepared, not executed. On an authorized reachable final/staging site with Playwright available:

`ARCADE_BASE_URL=https://approved-arcade.example/ node games/path-lab/browser-qa.cjs`

It visits all ten titles at 1280, 390 and 320 pixel widths, captures levels 001/050/100, detects page overflow, exercises hint, isolated solution replay, Escape cancellation, actual move buttons and undo, and records browser errors. The generated screenshots must still be inspected visually.

Final visual checklist:

1. Every title opens from the final lobby; browser Back returns to the expected category and search.
2. Dense Euler parallel bridges are distinguishable and all have matching numbered buttons.
3. Energy arrows, losses/caps, charger labels and full route table remain readable.
4. Tide phase digits distinguish current safety from next-step legality.
5. Dual maps fit on narrow touch screens; both goals remain visible.
6. Tether overlay follows the actual ordered rope at all board sizes and never crosses a blocked post.
7. Stair arrows flip visibly on arrival, including the traversed stair; key and exit are unambiguous.
8. Knight legal cells have equivalent large action buttons, and all games are playable without relying on color.
9. Tour matrix scrolls inside its own region without moving essential controls off-screen.
10. Replay cannot count as manual completion; storage denial, modal Escape and repeated navigation remain usable.

Release must stay unpublished until the parent all-80 acceptance gates, including real browser QA, are satisfied.
