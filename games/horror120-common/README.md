# 異常觀察：十五個夜間故事

15個繁體中文、手機優先的非血腥異常推理遊戲。每作100個穩定編號任務。沒有外部字型、媒體、AI服務、帳號、多人網路或執行期套件。

## 建置和驗證

在網站根目錄：

- `node games/horror120-common/generate.cjs` 決定性產生15份場景及1,500份動作證書；只有資料改版才需重新生成。
- `node games/horror120-common/build.cjs` 決定性產生每作入口、美術、說明、catalog。
- `node games/horror120-common/verify-all.cjs` 重新執行全部引擎、公開控制器、存檔與音效生命週期檢查，產生三份新報告。
- `node games/horror120-common/build-release.cjs` 綁定全部來源、資料、美術、測試與現有新報告；無循環自雜湊。

發布套件包含 release-manifest.json 的 sourceFiles 及 evidenceFiles，加 manifest 本身。報告不是執行依賴；驗證會先移除舊報告。沒有日誌、截圖、快取、壓縮檔或外部規劃文件依賴。

## 機制分工

- 走廊：回頭改寫門規則，信任地標維持同伴記憶
- 值班：監視碼／交班簿分辨真故障、倒序模仿、正常巡更，處理次序不同
- 唯一光源：人、燈、影子獨立位置，推燈與反射鏡改變空間追蹤
- 外來窗：承重窗圖與封窗壓力形成先後依賴，必須保住逃生口
- 斷訊天氣：實驗候選規則表，再處理真實前線及防護殘留
- 錄影：取得片尾認證後倒帶，回放直接拉近威脅，定位不可能的相鄰畫格
- 電梯：鏡像核身和票面先後關係，實際樓距消耗電量
- 呼吸房：主動呼吸挑戰，區別模仿序列與固定通風週期，僅收縮時可換房
- 空照片：逐排攝影揭露路面，人物缺影與物件一起消失有不同後果
- 備用鑰匙：新敲門挑戰與鞋號、腳步交叉核對，模仿者學過往公開挑戰
- 明日失物：三分支處理，前件歸還觸發後件因果連鎖，午夜逐件執行
- 第九乘客：票章與座位配對，隔離多出人影，逐站核對真實上下車人數
- 感官交換：三種感官犧牲換不同算式能力，依重建規律辨識嵌套夢門
- 餵影子：先教假習慣，誘使可觀察的局部學習政策作出守門承諾，再走真出口
- 模仿警報：私密線路授新規則；公開廣播被敵方記頻率／序列，假號能真的誘走已受教同伴

## 證明範圍與語義判重

每個 levels.json 恰好100筆。每個 proofs.json 恰好100條非空合法 witness，逐步解釋與動作等長。解題器只取得 view() 的公開證據；原始 config 的潛在真相不傳入。所有 witness 用同一 engine.step() 與真正公開控制器按鈕入口再次重播。每關還測試一條不同的合法成功路線，不宣稱唯一解。

semantic.js 依各作規則消除無關名字、圖案、座標平移、任意全局符號命名、獨立事件排序、無害正常微移等。每作 README 和 catalog 詳述其不可消除的引擎消費欄位。值班與車廂關卡以工作量／人數結構定義差異，不把換代碼、換座位算新關。

認證只涵蓋普通難度存在生還路線；不是任何對手都必勝。五作有獨立的局部 AI：唯一燈、呼吸房、備用鑰匙、影子、假警報。自由值班有簡單／普通／困難政策；其角色只接收允許的公開歷史或自有合法位置，密線、下一步、真出口等不傳入。另十作是固定環境和證據謎題，不冒稱計時器或亂數為 AI。難度控制只在適合作品的自由模式啟用。

## UI、存檔與生命週期

繁體中文目標、規則、證據、合法行動與結果完整可讀。點按或 Tab / Enter 可完成全部路線，前九個動作也可按1–9。333px/400px使用單欄、可折行按鈕與限制寬度的原生選單；桌面為場景／控制台雙欄。聲音僅補充氣氛，所有聽覺線索有文字。

音效初始關閉；只在明確手勢後建立 AudioContext。峰值增益0.025，每音源追蹤並在結束、靜音、暫停、重開、任務／難度／模式切換、頁面隱藏及 pagehide 停止且斷開。無背景播放演示計時器。「示範一步」每次點按走一個真實合法動作。

暫停與頁面隱藏會遮蔽場景及停止動作。操作採 revision token，舊按鈕和重複事件不能套用到新狀態。存檔僅保留合法歷史，還原重新播過每一動作；損壞存檔安全重開。提示或示範立即保存本次輔助來源，重新載入仍維持；手動、輔助紀錄分開且不覆蓋。

## 誠實的測試分層

引擎測試包括1,500個普通證書、1,500個成功替代路徑、公開觀察解題、陰性策略、非法／空／截斷證書、損壞存檔、語義重複與AI合法觀察／政策差異。控制器測試再經1,500條真按鈕索引路線，覆蓋輔助保存、暫停、重開、級別／模式變更、隱私與WebAudio模擬。

報告在執行前後綁定所有來源、測試與資料雜湊。此處不把模擬控制器或CSS來源檢查當作真正瀏覽器排版測試。333px、400px、桌面與正式hosted路由的實際瀏覽器證明由整合階段另行執行。
