# 倒帶特工

從失敗警报記住門碼，倒帶回檢查點另走安全路。

首次踩到 ? 感測格會暴露一段門碼並警報。按倒帶回到起點，位置、巡邏、道具重設，門碼記憶保留。記住所有感測格資訊後，可在起點停用感測網，再取得 ◇ 到 E。倒帶次數有限；這是遊戲規則，不算提示。

100 個固定離散任務。每關資料在 levels.json，逐步勝利見證在 witnesses.json；levels.js 為瀏覽器無須網路請求的相同資料副本。共用引擎 ../stealth120-common/engine.js 中的 rewind-agent 分支是本遊戲的實際規則。

驗證：從 arcade 執行 node games/stealth120-common/verify.cjs。

提示、示範、撤銷與玩家完成分開；示範不增加完成數。正規規則的倒帶不是協助。所有動作離散進行，不使用真實時間。沒有外部服務、安裝套件或追蹤。
