# 果凍摩天樓

用軟硬不同的積木搭樓，調整支撐與阻尼，抵抗強風和震動。

## 玩法與模型

每層是有質量的剪切彈簧。硬度限制變形，阻尼消散振動；偏心和過窄樓層容易斷裂。於預算內熬過整段風震，所有樓層不可斷裂。

一維橫向剪切樓層鏈；相鄰樓層的 Hooke 彈簧力與相對速度阻尼以等量反向力傳遞。外力為公開的正弦風與基座震動。剪切變形超過半寬比例便斷裂。材料硬度上限與成本是額外工程約束。不是有限元素樓宇分析。

## 100 關與可行性

每關有固定 ID、公開物理參數及客觀目標。關卡改變的是負載、材料限制、幾何、孔位、頻率、行程、側風、集料槽或其他實際被引擎使用的條件，不只換色或鏡射。

levels.json 是100個任務；proofs.json 每筆提供 construction、非空 witness、實際模擬 ticks 與結果。建構參數皆可透過精確數字欄位輸入；輸入 step=any，沒有藏在引擎裡才能設定的值。所有見證首先按開始；機械對戰另外持續前進並收低鉸鏈，其他實驗依建構自動演化。驗證還實際重播每關另一個不同的可行建構，並檢查空白建構和固定策略。這是存在性，不是唯一解或任意操作必勝。

這是建構型物理實驗，沒有需要假裝成 AI 的靜態計算對手。

## 操作與保存

滑桿、精確數字、加減按鈕可以完成全部施工。有位置的元件也可拖曳。P 暫停/繼續，R 重試；機械對戰另有方向鍵和觸控驅動。暫停、失焦、分頁隱藏會解除按住狀態。取消的觸控不會卡住動力。

建構、操作軌跡、選關和手動進度存在瀏覽器本機。重新載入時重播操作還原，停在暫停狀態。提示和示範保留協助來源；修改建構或重試不會洗掉協助標記。「空白重建」才能開始未協助的新挑戰。自由模式與協助模式不記手動通關。

## 驗證

從網站根目錄執行 node games/physics120-common/verify-all.cjs。它重播全部1500個發布見證、獨立檢查目標、測試1500組替代建構、固定策略負例、模型不變量、保存協助來源，以及15作首/中/末關的公開 DOM 控件。另以生成器重建資料並比對位元組。固定時間步為60Hz；單次模擬最多1800步，畫面軌跡最多120個取樣。

離線 DOM 測試不等於真實瀏覽器版面、觸控及部署驗收。這些由獨立整合驗收記錄；本目錄不假稱已完成。
