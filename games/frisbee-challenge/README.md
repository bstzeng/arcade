# 飛盤挑戰

把飛盤彎過柱子，以高度跨過矮牆落進圈內。

方向與力量控制平面速度，旋轉控制轉彎，仰角控制高度。矮牆可從上方越過；高柱要繞開。飛盤落地時中心進入目標圈才成功，挑戰限三次。

## 操作

滑鼠／觸控：移動類在球場拖曳；觸控方向按鈕可以長按。所有出手參數可用滑桿或數字輸入。WASD 移動，空白鍵主動作，Z/X/C 對應畫面特殊動作，P 暫停，R 重開。同機雙人用方向鍵、Enter 與 Shift，並有玩家 2 觸控按鈕。保齡球、撞球、冰壺、高爾夫等需等待球停再出手。

## 模型與關卡

運動型別：`frisbee`。實際規則位於 `../sports120-common/engine.js` 的獨立 handler，當前目錄 `engine.js` 是型別鎖定的公開介面。100 題資料位於 `levels.json`，瀏覽器離線鏡像是 `levels.js`。每個 witness 只含一般輸入和固定 tick，透過相同引擎的合法動作重播；不直接設定結果或球位。

這是簡化街機運動，不是專業物理或完整官方賽制。挑戰的對手是固定公開策略，證明的是合法可達勝局，而非對任意 AI 或人類的必勝策略。自由賽更改 AI 速度與反應，不能沿用挑戰證明。

每關的提示與示範都保留協助標記，不會增加獨立完成數。只有挑戰模式記錄關卡進度；自由賽與同機模式各自計分。資料存於瀏覽器 sports120:v1:frisbee-challenge，無帳號、網路要求或外部素材。

## 驗證

從 arcade 根目錄執行：

    node games/sports120-common/verify-all.cjs

該命令重播 1,500 個 witness、測試全部空解失败、重開／存檔／協助紀錄、獨立物理性質及合法 AI 行為。實際瀏覽器驗收另記，離線測試不等於視覺驗收。
