# 五子棋（自由規則）

## 啟動

由專案根目錄以靜態 HTTP 伺服器開啟 `games/gomoku.html`。無外部套件、帳號、網路對手或建置步驟。

## 遊玩

- 同機雙人輪流操作，或對戰簡單／一般／困難電腦。
- 人機可選先手或後手，三種難度使用不同搜尋深度及運算預算。
- 雙人悔棋撤回一手；人機悔棋撤回到你上一手之前，包含電腦回應。
- 棋局、設定及走法歷史自動保存在本機瀏覽器，載入時重新驗證每一步。
- 重新開局、修改進行中棋局設定均需要確認；取消不會清空棋局。
- 鍵盤方向鍵移動棋盤焦點、Enter／空白鍵操作、Ctrl／Command Z 悔棋。

## 規則

15 × 15 棋盤，黑方先行。橫、直或斜線連成五枚以上同色棋即勝。採自由五子棋，沒有禁手、三三或長連限制。

## 測試

```sh
node games/gomoku/rules-tests.cjs
node games/gomoku/controller-tests.cjs
```

規則測試涵蓋合法及非法走法、勝負／和局、各難度 AI 合法性、戰術及固定種子完整自我對弈。控制器測試載入實際 app.js 與輕量 DOM，涵蓋同機雙人、人機、悔棋、重開確認／取消、存檔重播／損壞／儲存不可用、晚到的 AI 回覆、鍵盤及頁面生命週期。測試報告為 `verification.json`；DOM 測試不等同實際瀏覽器視覺或無障礙稽核。

## 實作

`engine.js` 是純規則與搜尋引擎；`session.js` 管理歷史和非同步結果；`app.js` 管理繁體中文介面；`worker.js` 在背景運算，失敗時使用合法備援走法。較難 AI 有時間／深度上限，並非保證完美對弈。
