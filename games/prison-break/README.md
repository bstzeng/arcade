# 監獄越獄

按作息穿門、收集工具，在巡邏間挖出逃生口。

取得匙 K 和工具 T；按公開 4 拍作息穿過 D 門。到 X 挖掘 2～4 次打通地道，才可到 E。每次挖掘都消耗一拍，守衛仍巡邏。先觀察門與巡邏再動手。

100 個固定離散任務。每關資料在 levels.json，逐步勝利見證在 witnesses.json；levels.js 為瀏覽器無須網路請求的相同資料副本。共用引擎 ../stealth120-common/engine.js 中的 prison-break 分支是本遊戲的實際規則。

驗證：從 arcade 執行 node games/stealth120-common/verify.cjs。

提示、示範、撤銷與玩家完成分開；示範不增加完成數。正規規則的倒帶不是協助。所有動作離散進行，不使用真實時間。沒有外部服務、安裝套件或追蹤。
