# 格鬥與武器連段 · 15 款

十五套武器／身體規則，共用的部分僅限固定時序、移動、攻擊預備與命中、防守、生命週期與介面。每款都有 100 個實體障礙布局不同的格鬥挑戰、自由 AI 對決與同機雙人。

核心差異逐項在 definitions.js 與各遊戲 README 說明。engine.js 是唯一規則實作；coach.cjs 僅供離線搜尋證明，不會被瀏覽器或 AI 載入。瀏覽器的示範使用公開 proofs 中的普通輸入，會持續標記協助。沒有按 ID 認證過關、解碼密碼過關或動畫結束即成功。

## 重建與測試

    node games/duel120-common/generate.cjs
    node games/duel120-common/scaffold.cjs
    node games/duel120-common/verify-all.cjs
    node games/duel120-common/finalize.cjs

重建僅限本家族。驗證命令不改動任何來源、關卡或證明；它重新產生 verification-report.json。finalize.cjs 只建立來源綁定與發布清單。發布來源清單包含所有執行、產生、驗證、關卡與美術依賴，不依賴外部套件。

## 可解範圍與公平性

挑戰固定訓練 AI 的 28 格觀察延遲、22 格決策頻率及公開關卡節奏。自由 AI 才可切換三個難度；不能把訓練證明當成困難 AI 必勝。三個難度的玩家／對手初始生命、裝備、移速、傷害與耐力公式相同。對手讀延遲觀察，不讀輸入或證明。

精準步進公開完整合法控制向量及 1–600 格，對應證明的每個區段；因此不以手指的反應速度或隱藏控制API假冒可玩解答。

實際瀏覽器、觸控與部署 QA 由整合者另外執行。離線驗證不宣稱看過真實手機畫面。
