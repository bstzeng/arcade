# 播棋 · Kalah

獨立、無依賴的繁體中文雙人策略棋。從上層 `kalah.html` 開啟。支援同機雙人與電腦對戰、先後手選擇、簡單／普通／困難 AI、自動續玩、完整回合悔棋、重新開始確認、鍵盤操作及窄螢幕緊湊排版。這是自由對局遊戲，沒有預設關卡數。

## 規則

標準 6 坑 × 每坑 4 顆（共 48 顆）；逆時針播種，跳過對方棋倉；己方棋倉連走；己方空坑捕獲對面種子；任一方清空即掃盤結算。

## AI

簡單 1 層 / 600 節點 / 150ms；普通 5 層 / 14,000 節點 / 550ms；困難 10 層 / 110,000 節點 / 1,500ms。

迭代加深 minimax / alpha-beta；同一玩家連走時保留其最大化／最小化角色；搜尋採用最後完成的深度，受節點及實際時間雙重限制。Web Worker 不阻塞介面。Worker 不可用或發生錯誤時，改用 45ms / 3,000 節點的短搜尋。實際完成深度依裝置速度和局面變化；難度不等於保證必勝。

## 中斷與資料安全

- 每步將版本、遊戲代號、設定及動作紀錄存入 localStorage；重新載入時從初始盤面逐步驗證，忽略偽造的盤面。
- 存檔損壞安全回到新局；禁用儲存仍可操作。save() 回傳獨立快照。
- 人機悔棋撤回最近一次人類回合及其後電腦應手；同機悔棋撤回上一完整回合，包含連走或吃子。
- 重開和修改已有棋局的設定需確認，取消維持原局；AI 先行但尚未有人類操作時不能悔棋。
- 說明、確認對話框、背景頁面、pagehide、悔棋和重開會終止舊 Worker；代數和狀態修訂雙重檢查拒絕過期或重複回覆。返回前景／pageshow 恢復應進行的搜尋。
- Tab、Enter、空白鍵與方向鍵支援棋盤操作；九子棋可按 Esc 取消選子。棋盤更新保留仍合法的鍵盤焦點。

## 驗證

從網站根目錄執行：

```sh
node games/kalah/rules-tests.cjs
node games/kalah/controller-tests.cjs
```

規則套件包括固定邊界案例、三種實際 AI 預算的戰術測試、12 局固定種子完整隨機對戰、三種難度縮短預算的完整合法 AI 對戰，以及存檔重播驗證。`rule-results.json` 是實際執行結果；完整 self-play 為控制測試時間而縮短預算，不能當作整場困難 AI 棋力基準。

控制器套件使用確定性 DOM / 計時器 / Worker 模型，25 個測試涵蓋同機操作、悔棋、設定和重開的確認／取消、保存重載、錯誤存檔、禁用儲存、電腦先行、過期及重複回覆、前背景切換、pagehide/pageshow、Worker 錯誤和相容降級。另直接執行實際 Worker 程式，檢查三難度輸出合法且 token 正確。結果寫入 `verification.json`。

此 DOM 套件不會驗證實際瀏覽器像素、觸控命中區或版面溢位。實際瀏覽器視覺 QA 由整站驗收另行記錄。

## 檔案

- `engine.js`：純規則、合法走法、AI、棋譜重播
- `session.js`：設定、回合悔棋和存檔邊界
- `ai-worker.js`：獨立運算及回覆代數
- `app.js` / `style.css`：介面、生命週期與響應式樣式
- `rules-tests.cjs` / `controller-tests.cjs`：可直接使用 Node 執行的測試
