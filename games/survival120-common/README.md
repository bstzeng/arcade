# 生存製作與基地建造 · 15款

這個家族以15種獨立生存模型實現提案中的15個玩法，每款100個四輪任務。這些是有限、可重播的回合式資源規劃遊戲，不是無限地圖沙盒，也不是單一棋盤換皮。每款README公開精確模型。

## 任務與證明

100關從四種實際環境需求組態形成的256種四輪候選序列中，依遊戲對稱性正規化後挑選100種不等價時間序列。可互換的房間、農場、綁索節點、菌區、枝幹、維修機器會枚舉六種重新標號；冬眠的兩農場互換與木筏左右鏡像也正規化；重力站另外採取保守的全局花床需求互換正規化，即使新增的側面載重與翻轉方向已能區分部分配置，仍只保留這個較粗分類下的100關。以目標航位減洋流正規化相對航行需求，忽略僅作參考的腳數欄位。關卡變化在熱管需求、潮位／風限、毒土位置、機械負重、氧氣深度、枝幹成長等被引擎實際消耗的條件中；不是seed、標題或颜色改動。現有設備與材料跨輪保留，造成前後輪規劃的相互影响。每款的 `semantic-fields.json` 說明實際差異；不宣稱100張不同空間地圖。

`levels.json` 每關有穩定 missionId 和1～100 number；id識別所屬遊戲。`proofs.json` 的 id對應number，witness與alternateWitness都是公開動作ID序列，並非終盤狀態。主證明與替代序列逐項檢查合法動作，三種環境難度全部重播，推進前另由獨立條件檢查器確認。全部1500個主序列還使用發布的ui.js、原生select option與click事件完成離線DOM重播。

所有勝負由真實狀態條件判斷，不比對答案。替代序列包含有效配置、建造／搬運次序、分次灌溉與短睡；並不宣稱每關都有不同最終配置或唯一解。測試拒絕初始自動過關、未知動作、非法存檔、超額材料、錯誤熱流、缺氧、過重與其他專屬錯誤。

重力站的三個水箱有1／2／3重量與容量。每個花床只從同面箱子抽水，成功翻轉會實際扣除存水；補水每輪最多一次。上方面懸吊總重限3、下方面地板載重限4，重力翻轉改變哪一面承受懸吊負荷。水箱須先解锁才能搬，再重新固定。主解把重量分成3／3；替代解把2重放上方、4重放下方，並在每輪翻轉前搬移箱子。這不是無效的側面切換。

## AI的準確範圍

聲音獵場有實際追獵AI：只接收當下發出的聲音與公開音場；容易／標準／困難的聽覺門檻為2／1／0、反應間隔3／2／1工作時段、聲源記憶1／3／5時段。它追向記憶中最響聲源，平手追最新的聲音，不知道未來玩家輸入或答案。可先隔音，也可用靜默等待或外圍誘餌改變目標。

其他14款是環境規劃，不假裝隨機天氣是對手AI。全部遊戲有可選AI顧問，基礎只提一個當下合法動作，標準／精算依公開安全條件以束搜尋模擬兩／三步。顧問不讀witness，不保證全局最優。顧問深度與獵獸環境難度分開，避免把解答品質冒充關卡難度。

## 控制與存檔

每個引擎合法動作對應選單的一個option；選好後按執行，或用快捷的收集／推進按鈕。所有動作都有觸控、滑鼠與原生鍵盤操作。沒有精準定時要求；只有示範使用可暂停的650ms節拍。視窗失焦／頁面隱藏自動暫停。100關全開放選擇。

本機一份基地存檔保存最多500個動作與清楚的 manual／hint／demo來源，恢復時重新跑引擎而不相信任意state。進度分三組，每組最多100個合法關卡號。提示與示範永不自動算進手動成績；重開另起手動挑戰。拒絕超過25KB、不合法動作、跨遊戲與無效難度存檔。存儲被封鎖時遊戲仍可繼續。

## 再現與發行

- `node games/survival120-common/generate.cjs` 確定性生成15款HTML、插畫、語料、證明、README與catalog。
- `node games/survival120-common/verify-all.cjs` 重跑規則、DOM控制器、1500×2×3證明、獨立安全條件、語義及來源檢查，產生新的verification-report.json和release-manifest.json。
- 原始檔與語料不在驗證時改寫；報告綁定精確SHA-256。Manifest不包含自身雜湊，避免循環。
- DOM模擬的333／400／1100px參數不是實際瀏覽器布局證據。實際視覺、原生觸控、部署和大廳整合由父任務另行驗收。

全部邏輯及美術為本次本地原生JS／SVG實作，無外部依賴、字型、連線AI或追蹤。
