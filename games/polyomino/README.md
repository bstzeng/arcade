# 多格拼板

50 關，繁體中文、原生 JavaScript、無外部依賴。入口 `../polyomino.html`。

## 驗證方法

以連通小片分割棋盤，保留完整鋪排見證，再打亂每片初始方向。另用exact-cover最受限格搜尋重新求解；不要求唯一解，任何完整合法拼法皆可通關。

`levels.json` 儲存固定seed、布局、參考解與階段。`levels.js` 是同一資料的瀏覽器載入版。排除旋轉／鏡射等價題；拼板另以拼片形狀多重集合排除只重新切換拼片ID的重複。此初始關卡有解保證，不是玩家隨意操作都會成功。

## 可重現命令

從本資料夾執行：

- `python3 generate.py`：重建50關
- `python3 verify.py`：独立布局／終局審核與完整求解
- `node test.cjs`：實際遊戲引擎重播50份解答
- `node test-ui.cjs`：模擬DOM執行實際app程式，50關提示通關、解答播放恢復、撤銷、存檔与取消

## UI

固定單畫面桌面布局，手機縮排，極短螢幕或放大時允許頁面捲動以免截斷控制項。解答示範使用獨立狀態，不覆蓋玩家配置，也不記通關。每關獨立存檔，撤銷操作不含提示使用限制。存檔禁用時仍能玩。

## 提示

環線修正與唯一解不符的一條邊；拼板提供參考解下一片，若與現有另一種合法拼法衝突則說明並不強改狀態。沒有宣稱能證明任意玩家部分布局無解。

## 線上驗收

選第50關，提示一次、撤銷；進入解答示範到勝利，離開後確認原配置恢復；重整保留目前局面；重玩取消不改動；桌面主棋盤和操作列可見。模型DOM測試不是實體瀏覽器視覺驗收。
