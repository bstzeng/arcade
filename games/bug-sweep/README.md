# 反竊聽搜查

關閉干擾源，用兩個頻道的強度讀數交叉定位。

先關閉環境干擾。選頻道與格子掃描，讀數等於 100 減去距離的 10 倍；干擾開啟時會額外增加公開偏移。至少兩個不同位置的讀數只能指向一格時，才可在該格拆除。電量有限，錯拆損失電量。

100 個固定離散任務。每關資料在 levels.json，逐步勝利見證在 witnesses.json；levels.js 為瀏覽器無須網路請求的相同資料副本。共用引擎 ../stealth120-common/engine.js 中的 bug-sweep 分支是本遊戲的實際規則。

驗證：從 arcade 執行 node games/stealth120-common/verify.cjs。

提示、示範、撤銷與玩家完成分開；示範不增加完成數。正規規則的倒帶不是協助。所有動作離散進行，不使用真實時間。沒有外部服務、安裝套件或追蹤。
