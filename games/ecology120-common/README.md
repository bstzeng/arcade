# 生態演化與生命模擬 · 15 遊戲 / 1,500 情境

15 個獨立狀態轉移模型，共用無依賴的繁體中文介面與驗證工具。這些模型是教育性的遊戲抽象，不是科學方程、現實生態預測或完整遺傳模擬。

## 使用
以任意靜態 HTTP 伺服器開啟 games/<id>.html。無 CDN、外部 API、追蹤、登入或遠端 AI。操作為觸控/滑鼠按鈕，Tab/Enter、1–9、R 重置、P 暫停。環境預報完整公開；家譜的未觀察性狀除外，需先按「觀察」。

挑戰有 100 個可選目標情境，固定普通生物策略。自由實驗可以選簡單/普通/困難；只有含局部行為決策的五作啟用該選單。其餘是確定性自然規則，沒有宣稱 AI。自由實驗不記挑戰成績，也不宣告全部難度可解。

## 模型
- 一滴水的世界：耗竭與再生食物斑塊，細胞吞食、膜、吸氧、能量分裂。
- 會自己演化的島：每輪只改一項環境，三支系不同棲位及資源競爭。
- 長出翅膀之前：攀爬、滑翔、覓食特徵跨代保留；飛行能力有食物成本。
- 共生合夥人：持續的植物—真菌碳水交換、植物—昆蟲花蜜授粉連線。
- 潮間帶換班：三物種各有耐乾與抓地，附著高度調整潮水、浪擊與攝食。
- 菌網交換所：碳供應者與水接收者不同；菌網從有限地下水庫扣水並支付能量，雨水是公開的額外輸入。
- 百代家譜：兩性狀交叉繼承、隱性觀察、年長個體輪替與氣候存活。
- 遷徙不是直線：路線記憶降低後代能耗，濕地耗竭與閒置復原。
- 開花的時差：花期、花型、授粉飛行時窗、競爭花蜜、霜凍與局部覓食 AI。
- 失去天敵之後：捕食對兩種草食族群的不同壓力，連鎖改變植被。
- 海底噴泉居民：熱脈衝化能、容量溢流、代謝酵素、休眠與繁殖。
- 借來的外表：有毒警戒使天敵學習，無毒擬態利用記憶但讓它減退；不得只用隱蔽色通关。
- 沉睡種子庫：發芽比例、災年/豐年產種、休眠損耗與種子庫容量。
- 群居的代價：採集、分享、守望、育幼和制裁；鄰居依資源和互信選擇行為。
- 最後一塊棲地：有限預算的真實图連線、沿邊擴散、承載力、小族群消失與救援。

## 生成、驗證與證據範圍
- node games/ecology120-common/generate.cjs：固定算法與每作種子，生成候選環境、用同一引擎搜尋，再輸出 100 個可達成情境及非空合法行動證據。搜尋不是遊戲 AI。
- node games/ecology120-common/generate.cjs --check：重新生成並逐位元比對。可加 --game=<id>。
- node games/ecology120-common/assemble.cjs：生成可重建的 HTML、獨立 SVG、說明和目錄，建立全來源 SHA-256 清單。一般驗證絕不重寫來源。
- node games/ecology120-common/verify-all.cjs：清單前置绑定、1,500 實際引擎重播、獨立終局判定、每關公開控制器重播、替代勝利路徑、每個首輪合法操作、非法/截斷/空證據、正規化語義去重、固定單一操作反例、AI 合法性/層級差異/可見狀態反應、觀察隔離、儲存和生命周期、實際掛載的事件回呼（最小 DOM 模擬器），完成後再檢查來源未變。

可達成不代表解唯一、對任意對手必勝或每一套自由實驗難度都可解。100 任務的語義指紋去掉 ID/標題，保留實際引擎消耗的初態、環境時間序列、圖/生物屬性、資源與目標。難度不是用標題、色盤或無關 seed 假造。

verification-report.json 明確區別引擎、控制器和模擬 DOM；真正 333px、400px、桌面瀏覽器布局及發布后核驗由整合流程另做。此目錄不把模擬 DOM 當作真實瀏覽器測試。

## 存檔和輔助
每作独立 localStorage 鍵。操作軌跡重播驗證後才恢復進度；損壞資料安全回起點。提示、示範及曾用輔助的同關重試都有持續標记，且不覆盖原有自主成績。重新選關、模式、難度、暫停、離頁與手動中斷使舊示範計時回呼失效。無連續按壓狀態，不會卡住拖曳或鍵盤。

## 已知界限
沒有隨機自然災害、無限自由世界或科學擬真宣稱。圖表每個系列獨立縮放，適合觀察自身變化，不能以線高比較不同單位絕對值。程式及存檔在用戶端，不宣稱防竄改競賽系統。

## 零值的明確語義
島嶼支系、潮間帶群落的族群數 0 是吸收性滅絕，不能在較好環境中自發復活。食物網的草食者也只能用明確回引操作恢復。共生與菌網的 health 欄位則是固定存活植株的可恢復水分活力：0 表示枯萎但根系仍存活，並非個體數或死亡。

菌網的總水量逐步守恆：宿主水＋地下水＋累積吸收＝初始宿主水＋初始地下水＋累積預報雨水。碳不能轉成水；水庫空時只有未來降雨可補充宿主。所有簡單／普通／困難生物政策都讀取當下合法觀察；簡單策略用較粗的門檻與短視偏好，沒有固定輪流腳本。
