# 誘敵布置

把聲音誘餌投到側巷，讓守衛真的離開通道。

點格子選擇落點，站在距離 3 內可投聲音誘餌。守衛會沿可通行最短路到聲源，搜尋幾拍後返回崗位。投擲也耗一拍；誘餌有限。利用搜索窗口取得 ◇ 再到 E。

100 個固定離散任務。每關資料在 levels.json，逐步勝利見證在 witnesses.json；levels.js 為瀏覽器無須網路請求的相同資料副本。共用引擎 ../stealth120-common/engine.js 中的 decoy-setup 分支是本遊戲的實際規則。

驗證：從 arcade 執行 node games/stealth120-common/verify.cjs。

提示、示範、撤銷與玩家完成分開；示範不增加完成數。正規規則的倒帶不是協助。所有動作離散進行，不使用真實時間。沒有外部服務、安裝套件或追蹤。
