# 三人街頭足球

切換隊員、傳球跑位，穿過三人防線。

WASD 或拖曳移動控球員。傳球會送給下一名隊員並切換控制；切換可改選控球員。靠近足球可取得球權，射門要先有球。挑戰須完成一次傳球再進球。

## 操作

滑鼠／觸控：移動類在球場拖曳；觸控方向按鈕可以長按。所有出手參數可用滑桿或數字輸入。WASD 移動，空白鍵主動作，Z/X/C 對應畫面特殊動作，P 暫停，R 重開。同機雙人用方向鍵、Enter 與 Shift，並有玩家 2 觸控按鈕。保齡球、撞球、冰壺、高爾夫等需等待球停再出手。

## 模型與關卡

運動型別：`soccer`。實際規則位於 `../sports120-common/engine.js` 的獨立 handler，當前目錄 `engine.js` 是型別鎖定的公開介面。100 題資料位於 `levels.json`，瀏覽器離線鏡像是 `levels.js`。每個 witness 只含一般輸入和固定 tick，透過相同引擎的合法動作重播；不直接設定結果或球位。

這是簡化街機運動，不是專業物理或完整官方賽制。挑戰的對手是固定公開策略，證明的是合法可達勝局，而非對任意 AI 或人類的必勝策略。自由賽更改 AI 速度與反應，不能沿用挑戰證明。

每關的提示與示範都保留協助標記，不會增加獨立完成數。只有挑戰模式記錄關卡進度；自由賽與同機模式各自計分。資料存於瀏覽器 sports120:v1:street-soccer，無帳號、網路要求或外部素材。

## 驗證

從 arcade 根目錄執行：

    node games/sports120-common/verify-all.cjs

該命令重播 1,500 個 witness、測試全部空解失败、重開／存檔／協助紀錄、獨立物理性質及合法 AI 行為。實際瀏覽器驗收另記，離線測試不等於視覺驗收。

防守碰撞涵蓋傳球、射門和持球帶球；帶球時足球碰到防守員同樣會失去球權並結束該攻防小局。
