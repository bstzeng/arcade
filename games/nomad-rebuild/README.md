# 拆屋搬家的倖存者

災害逼近就拆屋撤離，在有限載重內保留重要模組，到新地點重建。

## 公開規則

先搜刮並製作目的地需要的模組，拆成箱再裝車。載重最多五；抵達後把必要模組重新組裝。留在原址的模組會失去，下一站須重新规划。

這是四輪、確定性的基地資源規劃遊戲。完整預報可隨時查看，沒有隱藏隨機事件。100關由256個四輪候選序列排除可互換節點標號與適用鏡像後選出100個不等價任務，並不是100張互不相關地圖。目的地必要模組組合的時間序列；五單位載重無法携帶全部，遺留模組永久失去，重製消耗材料。

每輪的推進由公開生存條件決定，不比對固定答案；符合條件的替代配置及操作順序也接受。所有材料、設備、任務與失敗判斷在 survival120-common/engine.js，UI與證明共用同一transition。

## 驗證範圍

levels.json 的100關均有 proofs.json 中的合法動作序列，另有替代操作序列。全部在 easy／normal／hard 環境重播；僅聲音獵場營地有會改變環境的獵獸難度，其他遊戲不顯示環境難度。各遊戲都有獨立的三深度顧問：基礎選目前合法一步、標準模擬兩步、精算模擬三步（束寬8／16），只用公开狀態，不讀witness。這是存在解證明，不是唯一解或對任意AI的必勝保證。

UI動作選單每個option value和engine.actions(state) 的 action ID 一一對應。觸控點選或鍵盤原生select均可操作全部證明。Enter執行、P暫停、R重開（表單取得焦點時保留原生鍵盤語義）。離頁或視窗失焦會暫停，回來須按繼續。

手動、提示、示範進度分開；本機存檔只保存最多500個合法動作並重播恢復，拒絕任意狀態注入。可選全部100關。

執行 node games/survival120-common/verify-all.cjs。離線DOM測試不等於實際瀏覽器／觸控／版面验收。
