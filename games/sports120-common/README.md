# 運動競技 · Sports120

15 個獨立運動規則、15 個入口、每款 100 個可重播挑戰；合計 1,500 題。全部是原生 JavaScript、Canvas、HTML/CSS，離線可用，沒有第三方 API、素材、字型或套件。

## 操作與模式

- 挑戰：100 題任選。開始前可以調整角度、力量、旋轉或仰角；不適用的控制會隱藏。
- 移動項目：WASD，單人也可用方向鍵；在球場拖曳或按住觸控方向按鈕。空白鍵主動作，Z/X/C 是畫面列出的特殊動作。
- P 暫停，R 重開。切換分頁、離開頁面、失去焦點均停止輸入；回到頁面需主動繼續。
- 自由賽：競技項目是先得五個街機小局的比賽；籃球是持球進攻與防守對決，棒球是打者與投手／守備對決，並非完整職業賽制。
- 同機雙人：競技項目提供玩家 2 方向鍵、Enter、Shift 與觸控控制。足球玩家 2 控制守門員，其餘防守員仍是 AI；棒球玩家 2 選快球／曲球，打者負責揮棒與跑壘。
- 精準項目是固定回合練習賽。冰壺是對既有守衛石的單壺戰術題，並未宣稱完整輪流投壺比賽。撞球自由賽是六球清檯；高爾夫與飛盤是九回合；射箭是五回合。
- 保齡球自由賽為十局，使用全倒／補中和第十局獎勵球計分。

## 引擎與可解承諾

`engine.js` 是唯一狀態轉移模型，有 15 個各自獨立的 handler，並共用有限的向量、碰撞和輸入正規化工具。瀏覽器以 60 Hz 固定 tick 推進，繪圖不更動狀態。重新開始不遺留舊計時器或示範事件。

各遊戲 `levels.json` 包含 `witness: [{tick,input}]`，只使用公開移動、出手、角度、力量、旋轉和特殊動作。`levels.js` 是完全相同的離線瀏覽器資料。重播沒有傳送門、直接寫入勝利或特權控制；球路、落地、碰撞和 AI 都仍由引擎決定。方向／力量的解答用一般滑桿 0.1 精度、旋轉 0.01 精度；移動由普通有速度上限的指向輸入驅動。

部分精準題採建構式生成：先模擬合法球路，再設定落點目標和可穿越障礙，最後以完整規則重新驗證。這是存在性證明，不是唯一解或獨立最優解。所有競技題只證明對本題標準公開策略的勝利，不能延伸成對所有人類／AI 的必勝保證。

AI 使用公開球位、球速、球員位置、體力或可見攻擊狀態。拍類與一般追球使用有延遲目標和速度限制，足球使用公開持球方向的有限速攔截，擊劍使用距離與可見預備動作，棒球守備以可見落球追球；棒球難度實際調整守備跑速與公開目標更新間隔。難度只調整速度／延遲，不瞬移、不讀取隱藏輸入或解答。

每款 100 個結構指紋是去除 ID、標題、提示、證據和見證後的實際規則參數。它證明沒有僅改名的重複題，不證明題目在所有幾何變換下均不等價。

## 進度來源

命名空間 `sports120:v1:<game-id>`。獨立完成、協助完成、看過提示、看過示範分開保存。看過提示／示範的關卡之後再完成，仍標示協助；示範永不增加獨立完成數。自由賽不更動挑戰紀錄。存檔以白名單清洗，損壞／禁止儲存仍可遊玩。

這是本機便利紀錄，不是防作弊排行榜或伺服器身份認證。

## 驗證命令（從 arcade 根目錄）

    node games/sports120-common/verify-all.cjs
    node --test games/sports120-common/ui.test.cjs
    node --test games/sports120-common/audit-regressions.cjs

第一個命令驗證全部 1,500 題的完整輸入重播、終局條件、空輸入失敗、無效輸入失敗、重播決定性、重開、AI 移動上限、碰撞守恆、特殊動作、保齡計分和協助紀錄。第二個命令載入每頁真正的 HTML script 清單，在離線 DOM／Canvas stub 執行實際 UI 控制器，測試 18 組載入、繪圖呼叫、操作、選關、示範、暫停、重開與離頁流程。

可重建題庫：

    node games/sports120-common/build-corpus.cjs

每個遊戲使用自己的固定種子，也能追加遊戲 kind／slug 只重建一款。重新生成後必須重跑全部驗證並更新來源雜湊。

## 已知限制

- 簡化街機規則與數值物理；乒乓球是帶上下反彈的旋轉 Pong 變體。
- 沒有線上多人、帳號、外部音效或專業規則認證。
- 手機 Canvas 保留完整球場；數字參數、說明和觸控按鈕位於其下方，較小球物件需要精準觀察。
- DOM stub 不做 CSS 排版、字型或實際觸控命中驗證。333／400 寬的真實雲端瀏覽器、視覺截圖和上線路徑驗收由整合階段執行，這裡不冒稱已驗收。

## 獨立審查修正（1.0.1）

- 足球：持球帶球與空中／地面傳球同樣接受防守碰撞判定，不能免疫攔截。
- 網球：回球第一次落地必須在接球方半場；落在擊球方半場立即判失分。合法截擊仍可在第一次彈地前發生。
- 棒球：入門／標準／進階 AI 的守備跑速是 0.72／1／1.28 倍，公開球位的追球更新間隔是 18／10／5 tick。相同輸入會產生可觀察的守備路徑差異，判定窗口仍依題目公開規則。
- 同機拍類／球槌雙方移動速度一致，停用的 AI 難度不影響玩家 2。
- 15 張獨立繪製的運動 SVG 大廳插畫置於各遊戲 `art.svg`；沒有遠端圖片。`art-preview.png` 是本地 SVG 合成預覽，並非瀏覽器截圖。

新增 10 組獨立審查回歸，包含上述故障情境、合法反例、追球速度／反應界限與 SVG 識別檢查。
