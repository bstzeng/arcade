# 棒球投打

辨識球路、抓準揮棒，判斷是否繼續跑壘。

投手在預告倒數後投球。球接近打者才揮棒；方向決定打出方向。擊中後自動跑一壘，按住「跑壘」可向下一壘前進；守備傳回時仍在壘間會出局。

## 操作

滑鼠／觸控：移動類在球場拖曳；觸控方向按鈕可以長按。所有出手參數可用滑桿或數字輸入。WASD 移動，空白鍵主動作，Z/X/C 對應畫面特殊動作，P 暫停，R 重開。同機雙人用方向鍵、Enter 與 Shift，並有玩家 2 觸控按鈕。保齡球、撞球、冰壺、高爾夫等需等待球停再出手。

## 模型與關卡

運動型別：`baseball`。實際規則位於 `../sports120-common/engine.js` 的獨立 handler，當前目錄 `engine.js` 是型別鎖定的公開介面。100 題資料位於 `levels.json`，瀏覽器離線鏡像是 `levels.js`。每個 witness 只含一般輸入和固定 tick，透過相同引擎的合法動作重播；不直接設定結果或球位。

這是簡化街機運動，不是專業物理或完整官方賽制。挑戰的對手是固定公開策略，證明的是合法可達勝局，而非對任意 AI 或人類的必勝策略。自由賽更改 AI 速度與反應，不能沿用挑戰證明。

每關的提示與示範都保留協助標記，不會增加獨立完成數。只有挑戰模式記錄關卡進度；自由賽與同機模式各自計分。資料存於瀏覽器 sports120:v1:baseball-duel，無帳號、網路要求或外部素材。

## 驗證

從 arcade 根目錄執行：

    node games/sports120-common/verify-all.cjs

該命令重播 1,500 個 witness、測試全部空解失败、重開／存檔／協助紀錄、獨立物理性質及合法 AI 行為。實際瀏覽器驗收另記，離線測試不等於視覺驗收。

AI 難度會改變守備跑速與公開球位的追球反應間隔：入門 0.72 倍／18 tick，標準 1 倍／10 tick，進階 1.28 倍／5 tick。同機模式固定標準守備，玩家 2 可選球種。
