# 偽裝通行

到更衣櫃換制服，穿過各有身分規則的檢查區。

彩色 A／B／C 門只讓相符制服通行。站在衣櫃 W，按身分按鈕更換。制服不會讓你穿牆；各區的門禁會驗證身分。取得 ◇ 後到 E。

100 個固定離散任務。每關資料在 levels.json，逐步勝利見證在 witnesses.json；levels.js 為瀏覽器無須網路請求的相同資料副本。共用引擎 ../stealth120-common/engine.js 中的 disguise-pass 分支是本遊戲的實際規則。

驗證：從 arcade 執行 node games/stealth120-common/verify.cjs。

提示、示範、撤銷與玩家完成分開；示範不增加完成數。正規規則的倒帶不是協助。所有動作離散進行，不使用真實時間。沒有外部服務、安裝套件或追蹤。
