# 元素沾染武鬥

依命中次序疊加火、水、雷、冰，讓殘留元素引發不同反應。

## 核心規則

先在對手身上留下元素，再換元素命中。水→雷麻痺、火→水蒸汽、水→冰凍結，順序改變效果。

三個專屬操作依序是「元素拳」、「切換元素」、「異元素踢」。第四個操作是正面防守。攻擊有實際預備時間、距離、方向、冷卻和耐力限制；橘色預備線提供反應機會，亮線是命中時刻。障礙阻擋角色和攻擊。正常防守減傷，開始防守的前 7 格可招架；招架不會一直生效。每格 1/60 秒。

關卡要求先完成「元素反應」，再擊倒對手。若只擊倒而未完成技巧，該關不算成功。每十關也有一次成功防守的明示目標。生命、技巧次數、場景、初始站位、敵方出手節奏和防守模式會隨關卡改變。所有關卡有不同的實體障礙配置，反射等價配置不重複。

## 操作與模式

- 玩家 1：WASD 移動，J／K／L 專屬操作，空白防守。
- 玩家 2：方向鍵移動，N／M／逗號專屬操作，句號防守。
- 觸控：每人一個類比搖桿和四個長按按鈕，可同時按多個。
- P 暫停、R 重開。頁面失焦／切換頁籤／觸控取消會釋放按鍵並暫停。
- 精準步進在暫停時公開所有一般輸入：水平／垂直 −1 至 1、四個出招核取方塊、1–600 格。一般動作和示範使用相同轉移函式；沒有修改血量、位置或結果的過關捷徑。

100 關挑戰固定使用訓練策略。簡單／普通／困難在自由對決才可選；同機雙人沒有 AI。自由對決雙方相同初始生命、裝備與體能。難度改變觀察延遲（28／14／6 格）、決策間隔（22／12／6 格）、防守與招式規劃，沒有額外生命、速度、傷害或讀取未來輸入。AI 只讀已發生的公開角色狀態與自己的狀態；決策早於當格玩家輸入生效。

## 提示、示範與存檔

技巧提示和示範會永久記錄該關「受協助」。重開、換關、重新載入不會抹掉這個紀錄。示範的勝局只增加協助完成，從不增加獨立完成。自由與雙人不記入挑戰進度。初次進入處於暫停，可先讀操作再開始。

存檔鍵：frontier120:fighting:v1:element-contact。不會讀取其他遊戲的進度，沒有帳號或外部服務。

## 模型與證明邊界

這是簡化街機戰鬥，不是完整武術或物理模擬。類型鎖定介面為 engine.js；唯一實際規則在 ../duel120-common/engine.js 的 13 號 handler。

levels.json 包含 100 個固定場景，proofs.json 包含各關的一般輸入與格數。每段 [格數,[水平,垂直,按鈕位元]] 是無損壓縮，位元 1／2／4／8 對應三個專屬鍵與防守，可同時按下。levels.js 是瀏覽器的同內容鏡像。合法輸入重播證明固定訓練對手下存在獲勝策略，不宣稱唯一解、不宣稱對任意人類或自由困難 AI 必勝。空輸入不能通關；通用亂按不能通關全 100 關。替代合法操作另有測試。

從網站根目錄執行：

    node games/duel120-common/verify-all.cjs

該指令重播 1,500 個證明，檢查不變量、負面策略、命中距離、專屬機制、AI 資訊與反應差異、進度隔離和控制生命週期。離線 DOM 和原始碼檢查不代表真實瀏覽器／手機視覺驗收；發布者另做實機檢查。
