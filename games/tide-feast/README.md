# 潮汐食物鏈 · Tide Feast

第一版原創單人、連續海域、大魚吃小魚遊戲。原生 HTML / Canvas / CSS / JavaScript，沒有建置、外部字型或網路依賴。入口是 `../tide-feast.html`。

## 玩法

- 從 2 cm 剛出生的小魚開始，先吃浮游生物。碰到食物就進食，滑鼠點魚不會直接加分。
- 頭上持續顯示實際體長；92% 體長以下的魚有綠圈、可吞食。112% 以上有紅色三角、會傷害玩家；中間為安全的同級灰色魚。
- 每一口只吸收少量營養，不是把魚的數字直接相加。相同比例的獵物在玩家越大時，提供的相對成長幅度越小。浮游生物的絕對增長也隨體型遞減。
- 每增長 28% 升一級，逐級增加游速；鏡頭平滑跟隨並拉遠。九種原創魚有不同身形、速度、轉向、游動習性，以及不同體型的個體。
- 沒有海域邊界。只維持附近活動魚群，持續補充適合當前食物鏈的魚；附近魚不會因玩家升級而突然變大。新魚從畫面外游入。

## 操作與容錯

- WASD / 方向鍵游動、空白鍵衝刺；或在海中按住滑鼠朝游標游動。
- 觸控在海中按住拖曳相對搖桿，右下衝刺按鈕支持另一指同時操作。
- P / Esc 暫停。失去焦點、切換頁籤自動暫停，不自動恢復。
- 三顆心。每次受傷有 3.2 秒保護，18 秒未再次受傷恢復一顆心。
- 最後一顆心用完會顯示捕食者及其體長。可保留 90% 體長（最低 2 cm）復甦，最高體長保留，出生及復甦有 8 秒護泡。
- 衝刺消耗體力，見底後必須放開並回復到 24% 才能再用，不能靠長按維持脈衝加速。

## 儲存

僅使用 `arcade.tide-feast.v1` 和其 `.backup`。不讀取、搬移、刪除其他遊戲的存檔。每 8 秒及暫停時儲存；重新開啟先暫停，玩家確認才開始。

主存檔損壞時讀取上一份完整備份；空間不足或存取被封鎖會警告，讓本局可暫玩。寫入前比較原始存檔與載入版本；跨分頁變更先暫停，可選讀取最新進度，或選本頁暫玩不儲存。重新開始要確認，只替換本局並保留最高體長。

## 驗證

執行 `node games/tide-feast/verify.cjs`，或在此目錄執行 `node verify.cjs`。

- `verify-engine.cjs`：核心規則、接觸進食、漸減成長、速度、存檔、損毀防護、衝刺、受傷／死亡／復甦、暫停、隨機種子重現、生成位置與 30 分鐘模擬壓力。
- `verify-ui.cjs`：離線 DOM 事件與儲存中斷流程；不是實際瀏覽器測試。
- `verify.cjs`：上述套件、語法、資產閉包、HTML 控制項與無外部依賴。

測試採用的 2 cm 新生自動游動只輸入方向與衝刺；它能看見整個附近物件池，比一般玩家有更多資訊，因此僅為可重現的成長／存活探測，不代表真人難度。10／100／1000 cm 的後段起始狀態明確標為 fixture，不宣稱玩家從出生自然到達那些體長。Node 引擎耗時不是瀏覽器 FPS，原始 Canvas 畫面不是 HTML／CSS 實際瀏覽器截圖。

第一版沒有關卡終點、付費、帳號、連線排名或長期伺服器存檔。真實瀏覽器、觸控手感、一般玩家難度與耐玩度需要另外驗收。

## 檔案

- `engine.js`：可在 Node 重播的純模擬；固定 60 Hz、最多 92 魚、180 浮游物、40 個短期效果。
- `render.js`：原創 Canvas 魚形、珊瑚剪影、光束、尺寸標示與食物方向提示。
- `storage.js`：版本化儲存、安全備份、跨分頁保護。
- `ui.js` / `style.css`：響應式介面、鍵盤／滑鼠／觸控、音效、手冊、確認與中斷流程。
- `art.svg`：原創目錄插畫；來源記錄在 `asset-provenance.json`。

所有魚形、插畫與合成音效均為此遊戲獨立創作，不包含其他作品的角色、美術或音樂。
