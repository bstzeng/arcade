# 物理沙盒與破壞實驗 · 15 作 / 1500 關

各作都有自身的因果物理更新函式、施工參數、資料與插畫；只共用安全生命週期、固定時鐘、建構編輯器和渲染工具。沒有「選一個預設答案」判題。

- 果凍摩天樓：一維橫向剪切樓層鏈；相鄰樓層的 Hooke 彈簧力與相對速度阻尼以等量反向力傳遞。外力為公開的正弦風與基座震動。剪切變形超過半寬比例便斷裂。材料硬度上限與成本是額外工程約束。不是有限元素樓宇分析。

- 連鎖拆除工坊：每棟建物為地面鉸接細長剛體。拆除器在7單位內解除支承，給予取決於側面的角衝量；其後重力矩產生角加速度。塔頂碰到下一棟會傳遞部分角速度。角度到水平即成廢料，左倒可能傷及保護區。不是爆炸或現實拆除模型。

- 垃圾機械大亂鬥：一維平台上的兩部剛體，輪胎牽引上限為 min(扭力/半徑, 摩擦係數×法向力)。半徑不足地面隆起時牽引下降。碰撞用彈簧接觸衝量，機身的轉動方程包含驅動/碰撞力矩、輪距回正與鉸鏈阻尼。玩家可驅動和收低鉸鏈。不是完整多體車輛動力學。

- 蒸汽壓力實驗室：集中參數鍋爐及氣室網路。鍋爐壓力由供氣與洩漏變化；閥門按壓差輸送氣體，活塞消耗面積×位移的體積。壓力×面積克服负載與速度阻力。公開的前置訊號接線決定閥門開啟順序。無理想氣體溫度場或真實蒸汽相變。

- 重力房間工坊：三個相鄰房間各有可調方向和強度的均勻加速度場，並使用線性阻力。粒子保有速度，穿過孔口時檢查連續運動交點；碰到邊界/孔緣失敗。兩個零件從不同位置出發，共用分區重力；必須都穿過孔並停進同一裝配接收區，不含任意三維組裝。

- 風洞運送計畫：每個風扇的局部氣流隨水平及垂直距離衰減。導流板角度改變風向；貨箱受重力與相對風速平方的阻力，迎風面積及質量改變加速度。前兩孔口與最後落點/落速均是客觀條件。導流板是風扇出口可調板，不提供 CFD 或獨立牆面流場。

- 共振拆玻璃：每片玻璃是 x'' + 2ζωx' + ω²x = F(t) 的受迫阻尼振子。三段音調可調頻率、振幅和播放時間；位移超過各材質門檻才破裂。相鄰保護器物也接受相同聲波。聲音以可視波形實驗呈現，不需要真的播放高音量聲響。

- 冰橋融化測試：每段冰桥與擋路冰塊分別累計按距離衰減的熱量。厚度隨熱量單調減少；簡化承重上限比例為厚度³/跨距。車輛以公開固定速度前進，需先融除每個擋路物又保持足夠橋厚。無流體、裂縫或真實熱傳 PDE。

- 沙堆崩塌研究所：有限圓盤顆粒，以重力下落、非完全彈性碰撞、位置分離及斜板摩擦近似砂流。礫石較大、較重且反彈較強；每個投料口可改配方，再等量混合成同一批入料。濕度增加切向耗散。三個收集槽按實際粒子位置計數。每關32～46顆，成對碰撞在固定有界工作量內完成。不是連續土壤模型。

- 繩網捕石實驗：巨石穿過固定捕捉高度且在錨點間時，視為落入三股繩網。每股繩只在長於鬆弛長度時產生拉力；阻尼依繩向相對速度耗散。總力決定巨石二維位置。檢查最低高度、峰值張力、末速與停留橫向位置。網袋接住的那一步是離散捕捉近似，非完整織網碰撞。

- 磁性碎片雕塑：圓形鐵片受到衰減磁場吸引、重力、阻尼與相互接觸。近距離相碰時形成彈性殘磁接合；磁鐵可在設定時間撤去。撤磁後須由地面接觸/接合保持輪廓、低速安定。殘磁接合是教學簡化，不是 Maxwell 磁場或可靠焊接。

- 摩擦係數遊樂場：沿下坡、上坡、平面的一維路徑積分切向速度。滑塊與滾球有不同轉動慣量；庫侖摩擦使速度消耗，靜摩擦可保持停止。可移動塗層起點，決定各段摩擦係數。目標是越過坡頂後靜止於容差區，非比對某個摩擦數字。

- 布料降落挑戰：五個布料質點以相鄰彈簧相連，三條彈簧繩連到包裹；每節布料承受質量、重力與相對氣流平方阻力，繩子把阻力傳到包裹。半傘寬、裁切比、繩長及左右差改變動態傘形。每60Hz步內做2個子步。不是高精度流固耦合，裁切用有效面積減少近似。

- 液壓巨手工坊：油缸推力=壓力×面積；速度受供油流量/面積限制；累計耗油等於每缸面積×位移。第一缸負載是重量，第二缸負載是薄殼彈簧。限壓閥及行程擋塊都會改變動作與破損。共享油量有限，沒有油液可壓縮性及複雜多關節手掌。

- 肥皂泡泡實驗室：氣泡總體積決定浮力；合併守恆體積但減少總表面積及阻力，破裂移除對應體積。貨物同時受側風阻力與重力。必須越過固定高度障礙，再以適當速度降入目的地。用正規化氣體密度近似浮力，不是現實肥皂泡承重預測。

所有輸入有界、模擬最長30秒，60Hz固定步，布料每步2子步。砂顆粒至多46顆、鐵片至多8片，接觸迴圈有明確上限。編輯施工立即回到預覽；不自動記勝。

每關至少兩個實際可行建構。證據中的語義正規化刪除ID、種子、文案、起始編輯樣板；部分位置任務再消除整體平移。剩餘的實際負載、形狀、材料、頻率、風與條件均有100個不同集合。固定首關建構、全最小、全最大及空白建構是公開負例，不把有限負例當成所有簡單策略不可能的證明。
