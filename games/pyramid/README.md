# 金字塔接龍：50 局可重播驗證牌局

入口：`../pyramid.html`。純 HTML/CSS/JavaScript，無相依套件、後端或外部資源。

## 本版規則

- 一副完整 52 張、無鬼牌，七層金字塔 28 張、牌庫 24 張
- 只有下方兩張均已移除的金字塔牌，以及廢牌最上方一張，可以使用
- 兩張數值合計 13 可移除；A=1、J=11、Q=12；K 單獨移除，花色不影響
- 牌庫一次翻一張至廢牌。背面朝上的牌庫頂牌不能直接配對
- 牌庫空時將剩餘廢牌按原順序翻回，最多兩次（共三輪），不得洗牌
- 清空金字塔即勝利，不要求清空牌庫與廢牌。無時間限制

基本配對、覆蓋、清空目標與三輪設定參考：
- [Arkadium 官方規則](https://support.arkadium.com/en/support/solutions/articles/44001851079--pyramid-solitaire-how-to-play-tips-scoring)
- [Brainium 官方規則](https://brainium.helpshift.com/hc/en/9-pyramid-solitaire/faq/269-how-do-i-play-pyramid/)

不同產品可能允許直接使用牌庫頂牌。本版採上列明示的廢牌頂牌限定變體。

## 如何保證有解

`generate.py` 使用固定種子（從 730001 起），逐步選擇當時合法露出的金字塔位置，再從標準牌組的 24 組互補數值配對與 4 張 K 中安排牌。配對可能是兩張金字塔牌，或一張金字塔牌與一張廢牌；不需使用的牌隨機插入牌庫中。每局保留完整的合法翻牌與移除 witness。

這是可解牌局構造法，不聲稱所有隨機洗牌都可解，也不聲稱任意玩家走法皆可解。所有 50 局都包含真實牌庫操作與金字塔覆蓋限制，未修改標準牌組。生成的數值／位置、牌庫順序不同；去掉花色後比較整個牌局，左右鏡像也視為同一局。50 局均通過此較嚴格去重，金字塔數值向量與牌庫數值向量各自也有 50 種不同排列。每局完整解答 37–47 步，實際翻牌 19–24 次，包含 5–15 組金字塔／廢牌配對。證明不依靠花色變換增加牌局數。

實際瀏覽器引擎為 `engine.js`。所有 50 份完整 witness 均在啟動遊戲時由該引擎驗證。`verify.py` 是獨立 Python 實作，不匯入生成器或 JavaScript 引擎；它使用座標集合檢查覆蓋，逐步檢查牌庫、廢牌、配對、唯一標準牌組、牌數守恆、最終目標與去重。

## 重現與檢查

在儲存庫根目錄（含 games 資料夾）執行：

```sh
python3 games/pyramid/generate.py
python3 games/pyramid/verify.py
node games/pyramid/test.js
node games/pyramid/test-ui.js
node --check games/pyramid/app.js
```

生成器會確定性地重建 `deals.json` 與供瀏覽器直接載入的 `deals.js`。50 局，共 2163 個合法 witness 動作。驗證器不只檢查最終版面，也逐步檢查每個動作。Node 測試重播真實遊戲引擎，檢查 52 張牌守恆、JavaScript/JSON 資料一致、存檔每個前綴、非法移除、K、配對、覆蓋牌、廢牌深層牌、三輪上限、不可變狀態與完成後禁止操作。UI 測試用無相依的 DOM 模擬操作真實 app.js，不能取代視覺瀏覽器 QA。

## 操作與存檔安全

選局、重玩本局、下一局、不限次數撤銷、下一步提示、播放完整解答、停止播放均可用。提示只在精確符合 witness 位置時顯示合法下一步。走法不同時，會先詢問是否撤銷到最近已知可解的歷史位置；不會偷偷跳牌或宣稱玩家的當前盤面一定可解。示範播放先確認重開，可中途停止並接手。

存檔只保存牌局 ID、操作序列、秒數與輔助標示，不接受任意牌面。載入時由引擎從原牌局完整重播；壞檔則回到第 01 局。儲存失敗不影響遊玩。計時從第一次操作後開始，只累計頁面可見且尚未完成的時間。

## 人工 QA 流程

1. 開啟 `games/pyramid.html`，確認初始 28 張金字塔牌與 24 張牌庫，頂層不可操作；底層數值清楚
2. 「下一步提示」亮出可移除牌或翻牌按鈕；照做後確認步數與清除張數。K 一次點擊；錯誤加總不可移除
3. 撤銷後確認牌面與牌庫恢復；重新整理繼續同一局；用不合法存檔確認安全重設
4. 手動連續翻牌偏離解答，按提示，確認先詢問撤銷步數；取消必須保留現狀
5. 「播放完整解答」確認後播放，按「停止播放」接手。重開示範時可用「重玩本局」→取消，卡牌必須仍可操作
6. 播放第 01 及第 50 局至勝利；確認清空 28 張即可勝利。完成後「撤銷」可回到上一手
7. 牌庫翻完可循環兩次，第三輪耗盡不可再循環；完整解答本身不需要循環
8. 桌面 1440×900、手機 390×844 與 320px 寬檢查字體、重疊、按鈕及捲動；鍵盤 Tab/Enter 操作，說明與確認視窗可按 Escape 關閉

本地視覺瀏覽器預覽未在此執行環境完成；最終視覺 QA 需在已發布頁面或可用的本機 HTTP 預覽進行。
