# 禁止重播

倒帶尋找錄影中的異常，但每次重播，都會讓畫面裡的東西靠近一步。

## 操作與目標
每格有兩個物件位置。正常相鄰畫格，各物件只能移動0或1格；跳兩格是異常。先播到片尾取得認證，再回放到異常發生的畫格標記。每次向後回放，畫中物靠近一級；距離歸零即失敗。可用一次隔離定格阻止下一次靠近。錯標或漏標不能封存。

所有觀察都有文字。點按合法行動，或 Tab / Enter；1–9 觸發前九個行動，H 提示、R 重開、空白鍵暫停。每次示範只走一步。所有提示和示範永久標記本次路線為輔助，不覆蓋手動通關。

## 任務與證明
100個穩定編號任務，位於 levels.json。proofs.json 每條 witness 和逐步解釋均用 engine.js 真實狀態轉移執行。解題器只接收 view() 的公開資訊；不讀原始真相或保存解答。正常挑戰鎖普通規則；自由值班不計入認證紀錄。這是存在路徑證明，不宣稱唯一解、任何對手必勝或現實科學／心理模擬。

### 語義差異
16格錄影中的兩個不可能移動位置，共選100種時間結構。忽略正常微移、物件名字、坐標偏移與圖像外觀。回放距離和片尾認證消耗實際操作。

## 存檔與邊界
存檔只含經過驗證的行動序列、模式、任務和輔助標記；還原重播完整合法動作。損壞資料回到安全起點，手動／輔助列表各自校驗。沒有無人值守的演示計時器。重開、模式／難度改變、暫停、隱藏及 pagehide 停止並斷開所有音源。

## 抽象與已知限制
此作是回合制小型異常推理模型。危險是可讀規則的虛構後果，沒有真實的人身風險、機器視覺或外部AI。美術與文字共同提供氣氛；所有必要資訊以文字明示。認證不含任意自由操作都可挽救的保證；不可逆錯誤可重開。實際瀏覽器與 hosted QA 由整合階段另行執行，離線測試不冒稱實際瀏覽器證明。
