# 文字與語言：十五種有界語言遊戲

繁體中文、本機運行、每款 **100 個可選關卡**。這是可檢查的語言規則遊戲，不是通用自然語言理解系統。沒有外部 API、帳號、網路對戰或遠端模型。遊戲資料和同義表直接隨檔案提供。

## 啟動與交付

從任一 `games/<slug>.html` 進入。入口只載入自身的 `levels.js`，不載入整個家族。根目錄大廳由整合者維護，本家族沒有修改既有遊戲或根目錄程式。

- `catalog.json`：15 個正式名稱、slug、路徑和展示資料。
- `proposal.json`：本次授權的原始家族規格副本。
- `engine.js`：同時用於 UI 與驗證的純函數引擎、語意判讀與 reducer。
- `app.js` / `style.css`：共用控制器與行動版版面；各遊戲使用不同操作模型。
- `generate.cjs`：可重建的語料／關卡生成器。核心漢字、場景、同音字、語意詞表、敘事、詩句均為人工編寫，關卡由有意義的任務組合構成，並非聲稱 1,500 篇獨立手寫文章。
- 各款 `levels.json`、`levels.js`、`proofs.json`：執行資料與可重放的合法輸入。
- `verification-report.json`：實際來源 SHA-256、解答、反例、替代解與語意去重結果。
- `ui-verification-report.json`：執行真正控制器的模擬 DOM 測試，**不是瀏覽器視覺測試**。
- `release-manifest.json`：整合者用的來源、命令、AI 觀察範圍和證明範圍。

在倉庫根目錄執行：

```sh
node games/words120-common/generate.cjs
node games/words120-common/build-assets.cjs
node games/words120-common/test-generation.cjs
node games/words120-common/verify.cjs
node games/words120-common/ui-tests.cjs
node games/words120-common/build-manifest.cjs
```

生成器不使用隨機數、網路或外部套件。驗證器會重新計算語意簽章，不信任資料內的 `semantic` 標籤。字典題更會消去陌生詞重新命名、詞序、例句次序及四詞排列，證明 100 組觀察圖結構不同。精準命名的最小成本由獨立的完整真值表動態規劃驗證；允許 `非` 不會降低此證明，因為德摩根律可將否定移到葉節點而不增加屬性詞數。

## 操作、教學與紀錄

- 上／下一關及下拉選單直接選 1–100 關，無需先破關。
- 一般關卡選詞卡、組件、句式或直接編輯文字；按「檢查／執行」送出。鍵盤 `Ctrl+Enter` / `Cmd+Enter` 也能送出。所有按鈕都能 Tab／Enter 操作。
- 斷詞關點擊字間的切口；一字改命每按一次只改一個「已／未」字，立即顯示因果結果。
- 禁字旅人按順序通過三站，每站確實新增一個禁字。其餘遊戲無計時壓力，不需要暫停。
- 提示顯示分析與支援詞彙；解答示範逐步使用同一 reducer，按「下一個示範步驟」觀看。不是只在畫面填一個成功標籤。
- 提示或示範使本次嘗試成為 assisted；完成時不記作自行解題。重新開始是新嘗試，歷史的 assisted 紀錄仍保留。自行及協助成績分開保存。
- 本機儲存每款獨立、版本化且經型別檢查的完成紀錄。損壞或無法保存時正常繼續並說明限制。字典遊戲保存已解出的詞義筆記。
- 重置、換關、離開頁面、人工修改輸入都取消未走完的示範。沒有 AI 計時器或背景網路請求。

## 十五種遊戲和關卡變化

| 遊戲 | 真正操作與 100 關內容 | 驗證方式／限制 |
|---|---|---|
| 標點逃脫 | 10 組人工校寫的標點歧義，25 種雙告示組合 × 4 種目標讀法 | 漢字完全不變；只接受題目公布的有限句法及等值句末符號。範圍、否定、引述、反問會改變通行意思。語氣或稱呼有上下文依賴，這裡採明示的讀法，不宣稱排除所有現實語用。 |
| 偏旁修理舖 | 30 個真實漢字的可視部件與左右／上下／包圍／品字結構，100 種雙件修復 | 部件及位置由字形構成檢查；偏旁變形如亻、氵、忄、訁、釒、⻊明列。不是把所有部件都當字典部首。 |
| 縮字電報 | 12 種實際操作，100 組有先後次序的雙操作任務 | 六漢字限制；隊友只對電報作詞典解析，允許全部列出的同義動詞、名詞和標點分隔。 |
| 外星文法課 | 6 種基本詞序及 4 種前置／後置格標記與句首／句尾修飾的方言；10 種主賓、動作、否定、數量任務 | 從對照語料組句，解譯器輸出角色動作。格標記方言可自由調整三個詞組次序；nu／zo 依方言在句首或句尾。動畫為視覺示意。 |
| 諧音換景 | 16 組國語同音同調字，100 組雙障礙組合 | 同音、同調且具情境用途才接受；包含物件、數字及動作的魔法轉換，非字形相似替換。 |
| 指代偵探 | 20 個人工事件，100 種雙案組合；每關解四條指代 | 用交還、物主、用途、空間、引述與事件角色限定指代，不能只挑最近姓名。 |
| 禁字旅人 | 20 種用品、30 種語意特徵及同義描述；100 條三站路線 | 禁字累積；店員看公共商品與傳出的描述，以特徵交集推理。若不唯一便要求補充。詞序不限，同義詞可換。 |
| 譯意接力 | 20 組完整事件與條件，轉為公告、童話敘述、說明書、新聞、便條 | 正文按事實欄位比對，非整句比對；兩項資訊可換序。使用文體卡，童話是敘事口吻，不能偷偷添加虛構事件。 |
| 一字改命 | 10 組因果場景，各有 10 個不同的故障／初始敘事 | 每回合確實只改一字，經 AND／OR／NOT 因果網路重算事件；可按任何有效順序修復。顯示完整連鎖，不宣稱開放式故事理解。 |
| 隱喻畫廊 | 20 個作品題材、12 組有語意的功能／關係比喻，100 個目標與干擾展間 | 不傳名稱或外觀，只用比喻詞卡；隊友從公開的寓意配對與訊息求交集。不把比喻解讀當成唯一的文學判斷。 |
| 語氣調音台 | 20 件事實 × 正式、禮貌、朋友、緊急、安撫 5 種語域 | 起句、事實句、收尾共同符合明示場合；每關至少兩種保真句式。語域適切性限本題。 |
| 失落字典 | 100 種非同構的四詞觀察集合；不同物件共同出現的線索 | 詞串與畫面集合做一一對照，驗證所有例句而非死比標準答案；字典筆記逐步累積。 |
| 斷詞探險 | 20 組人工詞法場景組成 100 個雙路口任務 | 原字串不變，只插斷詞；多種合理詞法若指同一場景都接受。包含學生／學生會、球拍／拍賣、小和尚／小和等真正歧義。 |
| 押韻救援 | 50 個冒險行動，各有五言立即行動與七言協同行動 | 字數、語意、協作條件、韻部同時檢查。採明示的國語寬韻分組，非古典平水韻；不評平仄。每個行動有同義句，支援「一起／一同」。 |
| 精準命名師 | 完整四維圖案世界中 100 個經屬性置換及正反翻轉後仍不同的目標集合，最短 1–7 個屬性詞 | 真正解析布林描述，以真值集合及最少屬性詞數判定；任何等價最短式皆可。括號與連接詞不計長度。 |

## AI／本機夥伴的資訊邊界

1. 電報隊友只收到 `message` 和公共操作詞典。它分詞得到操作序列；外層評分器才與私有目標比較。
2. 外星機器只收到句子、方言規則及公共詞彙，輸出動作、施事、受事、否定及數量；不讀目標。
3. 店員／畫廊隊友只收到公共候選集合、線索詞典、傳出的線索及禁字。它求候選交集，不讀目標。
4. 譯意接力與語氣調音台是明示文體／事實檢查器，不冒稱自主對手。其餘是解謎驗證器，不強加不必要的 AI。

測試將假目標及假答案加入觀察物件，要求夥伴輸出不變；並測試未知詞、空訊息、重複線索、非法構句與錯序命令。這是本機程式的資料流邊界，不是對惡意使用者瀏覽器的保密承諾。

## 證明與尚待驗證

所有 1,500 關的 witness 使用實際 engine/reducer 重放。另測合法替代、空白與不完整作答、語意反例、保存與重置、重複提交、示範的協助分類；精準命名另外窮舉證明最短屬性詞數。解答證明是有界規則下的可達性，**不宣稱所有解唯一**，也不宣稱人類對文學比喻的判斷唯一。

DOM 模擬覆蓋 15 路由的第 1／50／100 關示範、實際輸入控制、人工完成、提示、換關與人工輸入取消示範、損壞／不可用存儲。版面採 333／400px 與桌面可伸縮設計，但本家族建置者未操作真瀏覽器；畫面、窄螢幕及最終發布路由需由整合者另行驗收，不能把 DOM 報告當成截圖證據。
