# Real-browser checklist (root integration owns this pass)

Offline controller replay is not browser geometry verification.

At 333px, 400px and desktop widths:
- Open every entry and verify exact title, distinct cover and both JSON data requests.
- Play representative primary and alternate paths; verify first, middle and last mission selection.
- Open native selects and confirm all long labels remain usable without page-level overflow.
- Read dense relationship tables with internal scrolling; open full journals and chapter rules.
- Open/close help, request a contextual hint and run a demo. Assisted results must not become independent records.
- Independently complete a mission, demo the same one, reload and verify the earlier record survives.
- Change mission, mode and difficulty during a story. There are no deferred timers to leak into the new story.
- Reload midway and after an ending. Inspect keyboard Tab/Enter and visible focus.
- Confirm challenge difficulty is disabled and normal-only scope is visible; free-story difficulty changes actual character responses.
- Inspect radio caller consequences, late letter queue, pawned-memory disabled choice, post-ticket island actions, old/young document locks and unattended retirement events.

Capture verification outcomes as new source-bound root evidence. Do not publish screenshots or logs into the release source list.
