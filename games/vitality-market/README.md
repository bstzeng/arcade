# 生命值當貨幣

用最大生命購買力量，擊破危險獵物贖回本錢。

## 精確遊戲變體

工坊每次永久抵押 4 點最大生命，換攻擊、護盾或吸血。當層精英被擊破會贖回 3 點抵押生命；越早購買越強，但殘血時要先找療癒池。

三層、九乘九、確定性回合制戰術地城。共用移動、牆壁、敵人視野與攻擊預告，但每款有獨立構築狀態與作用於戰場的規則。不是即時動作遊戲。每層先選構築、探索四個相通房間、擊倒守門首領，再走到出口。

方向鍵／WASD 移動；Shift＋方向近擊；Ctrl＋方向能力；空白使用面向能力；Q 防守、E 互動、F 下樓、P 暫停、R 重來。觸控選動作後點方向，所有特殊構築有獨立按鈕。

## 關卡與證明

100 場固定種子遠征，每場三層；每層四個房間的門位、冰／熔岩位置、敵人出生與類型、生命強度、起始構築條件一起變化。levels.json 是固定引擎生成器的關卡描述；proofs.json 是經遊戲引擎逐步重播的合法操作見證，proofs.js 在瀏覽器播放同一套見證。限定標準 AI 下的可達性，不是唯一解、任意敵人策略必勝或進階 AI 必勝。

100 挑戰鎖定標準 AI。自由遠征的輕鬆／標準／進階改變觀察距離、追蹤路徑、保持距離、攻擊預告時間，不能將標準示範當成所有難度的證明。敵人只使用可見玩家與短期目擊記憶；不讀取玩家下一步。

## 進度與中斷

每步保存操作紀錄，重載重新重播並驗證，預設暫停。提示／示範的協助標記一同保存。重來、換關、暫停、頁面隱藏與退出取消示範計時器。手動完成、協助完成和自由模式分開。

## 重跑驗證

從 arcade 執行：node games/rogue120-common/verify-all.cjs。重建種子與見證：node games/rogue120-common/build-corpus.cjs。檢查含全部見證、地圖可達性、敵人難度因果、每種構築專屬規則、替代構築及未協助紀錄的離線控制器測試。實際瀏覽器驗收由主整合另行記錄，不把離線測試冒充瀏覽器驗收。
