# 四季王國戰爭

趁春夏儲糧與進軍，安排秋收，冬季封山前建立防禦。

## 規則
春季徵募較多、夏季開山道、秋季農田收糧、冬季封山並消耗糧食。休戰會令雙方停止攻擊一輪。

取得邊地，設農田與糧倉，平安度過指定冬季。 任務框列出該關的精確地區、數量與時限。這是原創離散回合抽象模型，不是現實軍事模擬。全圖資訊公開，只有尚未結算的指令保密。

## 操作與模式
選地區以篩選命令，或顯示全部命令。每個合法命令都出現在原生下拉選單；花費與兵力列在名稱和預覽中。每輪提交一項指令。雙方從同一開始狀態封令：建設先結算、對向軍團先抵消，再按固定青先赤後處理到達；提交先後不改變此順序。戰役固定普通 AI；自由 AI 對戰提供簡單、普通、困難；同機熱座雙方從同一公開快照秘密選令。自由對戰到回合限度以領土、兵力、城防和預算計分。

## 有解的精確意思
100 個穩定編號戰役各有非空合法行動紀錄，重播至實際引擎的完整勝利條件，並以獨立條件函式核對。只證明在指定起始狀態與固定 normal-public-state-v1 對手策略下存在勝利路徑，不是任意對手必勝、唯一解或所有難度可勝的宣稱。地圖由不相同的無向樹拓樸產生；道路狀態、地理深度、目標省、設施需求、期限與數量會實際作用於移動、支援和勝負。

## AI 與公平性
對手只收 view() 的公開地圖與歷史，不收到本輪玩家命令或封存指令。簡單查看至多10個候選且採淺層兵力判斷；普通比較至多80個候選的進攻盈餘、目標距離與徵募價值；困難比較至多500個候選，再考慮鄰近敵軍反擊、任務關鍵點和保留後方。這些是確定性的本機策略，不宣稱大型語言模型。

## 提示、示範與保存
提示會把本局標成協助並維持存檔標記。示範使用獨立狀態，不能增加完成紀錄。指令結算後不可悔棋，避免看過對手密令再重選；可清除未送出的草稿。保存完整輪次行動，讀取會逐步合法重播；熱座尚未結算密令不持久保存。
