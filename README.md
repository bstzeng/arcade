# Arcade · 遊戲小宇宙

輕量、響應式的繁體中文遊戲入口網站。原生 HTML / CSS / JavaScript，無套件、無外部字型、無追蹤，也不需要建置。

六十七款遊戲均可直接遊玩，支援滑鼠、觸控及鍵盤操作。

## 遊戲目錄

- **數字實驗室**：滑動合併相同數字，挑戰 2048。
- **迷宮漫步**：穿越隨機迷宮，找到出口。
- **方塊計畫**：將方塊放入 8 × 8 棋盤，填滿整行或整列即可消除。
- **記憶配對**：翻開卡片，找出相同圖案，挑戰更少步數。
- **小小星球**：採集資源、培育森林、探索與修復星光塔。
- **反應時刻**：等待訊號再出手，測試反應速度。

### 五張經典牌桌 · 250 副驗證可解的牌局

每款提供 **50 副固定、不同且已完整重播驗證可解的牌局**。可以選局、重新開始、撤銷、查看提示與解答示範。手動遊玩若偏離已知解答，提示會以當前局面可用的規則或重新開始解答引導，並不把任意中途狀態宣稱為保證可解。

- **經典接龍（Klondike）**：標準 52 張牌、七列牌陣，每次翻一張；牌庫可依原順序不限次數回收，同花色 A 至 K 收牌
- **新接龍（FreeCell）**：52 張正面牌、八列牌陣、四個暫存格，依空格容量限制整串移動
- **蜘蛛接龍（Spider）**：一花色 104 張牌，十列牌陣、44 張覆牌、五輪各十張牌庫；空列時不可發新牌，完成八組 K 至 A
- **金字塔接龍（Pyramid）**：28 張金字塔與 24 張牌庫，翻一張、最多回收兩次；露出的牌合計 13 消除，K 可單獨消除，清空金字塔即勝利
- **三峰接龍（TriPeaks）**：三峰共 28 張、初始底牌一張、牌庫 23 張；相差一點即可接牌，A 與 K 相連，清空三峰即勝利

所有牌局都保存完整合法動作證明，不以未驗證的隨機洗牌冒充「可解」。驗證程式逐步檢查發牌結構、卡牌守恆、遮擋／覆牌、移動規則與最終勝利，也檢查牌局不只是重新換花色或重新排列欄位的同一布局。資料與生成／求解程式隨原始碼提供。

### 十款單人益智棋盤 · 500 個驗證可解的關卡

每款 **50 關**，從入門逐步增加棋盤、配置或解法的複雜度。全部保存可合法完成的解答證明，逐關重播驗證；排除只換編號、顏色，以及規則允許的旋轉／鏡射等價配置。支援選關、重新開始、撤銷、提示、解答示範與本機存檔。

- **塞車棋（Traffic Jam）**：沿車身方向調度車輛，讓紅車到達出口
- **華容道（Sliding Blocks）**：四組不同大小方塊配置，挪出主角通往出口的空間
- **推箱子（Sokoban）**：箱子只能推不能拉，將所有箱子送進目的地
- **獨立鑽石（Peg Solitaire）**：跳過相鄰棋子，最後在指定位置留下唯一一枚
- **熄燈棋（Lights Out）**：切換自己與相鄰格，熄滅整片棋盤
- **冰面滑行棋（Ice Slide）**：三部機器人互相擋停，讓指定機器人精準停在目標
- **橋樑棋（Hashi）**：依島上數字搭橋，橋不能交叉，所有島嶼必須連通
- **帳篷棋（Tents）**：依行列數字放帳篷，與樹一對一配對，帳篷不能相鄰
- **環線棋（Slitherlink）**：依數字畫出單一閉環，不分岔也不能分裂成多個環
- **多格拼板（Polyomino）**：旋轉、翻面、放入各種連通拼片，鋪滿全部空白格

橋樑棋、帳篷棋與環線棋各 50 關都經完整搜尋確認只有一個解；其他遊戲允許多條合法路線或多種合法完成配置。多格拼板不限定參考解，只要完整合法鋪排即可通關。保證的是初始關卡有解；推箱、跳棋等遊戲仍可能因玩家走法而進入死局，屆時可撤銷或重開。提示會依各款能力提供當前局面解答、已驗證路線引導或明確的衝突說明，不把未證實的中途狀態宣稱為有解。

所有規則引擎、固定關卡、生成程式、解答證明與測試都隨原始碼提供。`node verify-puzzles.cjs` 執行 500 關的完整驗證並產生 `puzzle-verification-report.json`；模擬 DOM 的控制流程測試與實際瀏覽器視覺驗收分開記錄。

冰面滑行棋保存通關、個人最佳及最後選擇的關卡；重新整理會重開該關，不保留中途棋子位置。其他益智棋盤可接續已保存的盤面。

### 十款邏輯推理 · 新增 500 個唯一解關卡

每款 **50 個固定、不同、已驗證唯一解的關卡**。此批不只重播一份參考答案：各規則求解器會搜尋並計數可能的完整盤面，並另有獨立驗證程式交叉核對。排除旋轉、鏡射或純標號變換造成的等價關卡。加上原有 500 關益智棋盤，站內共有 **1,000 關益智挑戰（此批發布時）**。

- **數繪（Nonogram）**：按照行列的連續色塊長度完成黑白圖案
- **數牆（Nurikabe）**：每座島只有一個數字，島面積符合線索；海水連通且不能形成 2 × 2 水域
- **磁鐵棋（Magnets）**：每塊骨牌為正負磁極或空白，符合行列正負數量且同極不能相鄰
- **戰艦定位（Battleships）**：找出指定艦隊，符合行列數量，艦艇不能相碰（包含斜角）
- **不等式數獨（Futoshiki）**：行列數字不重複，並符合已給定數字與不等號
- **數和（Kakuro）**：每段數字不可重複，橫直加總皆符合線索
- **黑白圓圈環線（Masyu）**：白圈直行並在前後至少一側轉彎；黑圈轉彎且前後皆須直行；全部連成單一閉環
- **旋轉水管（Net）**：旋轉線段，使所有格連通且不成環；對稱線段的相同接頭狀態只算一種解
- **棋盤雷射（Black Box）**：從四邊探測吸收、反射與出口，推理固定數量的原子位置
- **天際線（Skyscrapers）**：行列填入不同高度，從四側可見的樓數符合線索

Black Box 的唯一性是對**完整四邊可觀測訊號**與已知原子數作窮舉判定；玩家只發射部分光線時，仍可能有多種候選布局。Net 的解以實際接頭遮罩計數，不把直線旋轉半圈等相同物理狀態算成不同解。

新作支援 50 關選關、撤銷、提示、重開、解答預覽與經驗證的本機存檔。解答預覽不直接覆寫玩家盤面或冒充完成。完成判定依各遊戲規則檢查；提示的使用會依遊戲標記或計數。

`node verify-logic.cjs` 一次驗證新增 500 關的獨立唯一解計數、規則邊界、控制器流程、50 關資料與大廳入口，產生 `logic-verification-report.json`。`node verify-all.cjs` 可連同先前的接龍與益智棋盤全部重跑；模擬 DOM 測試不等同於實際瀏覽器視覺驗收。

### 十款經典益智 · 再新增 500 關

每款 **50 個固定關卡**，連同前兩批共 **1,500 關益智挑戰（此批發布時）**，另有 250 副接龍牌局。大廳新增「經典益智」分類與十款專屬封面。

- **數獨（Sudoku）**：由迷你盤面漸進至標準九宮格，行、列與宮內數字不重複，各關只有一個完整解
- **踩地雷（Minesweeper）**：固定且已驗證免猜的棋盤，由安全起點出發，以已揭露數字與總雷數逐步推理
- **十五數字拼圖（Fifteen Puzzle）**：從九宮格暖身至 4 × 4 棋盤，滑入相鄰空格，將數字排回順序
- **漢諾塔（Hanoi）**：一次移動最上層圓盤，大盤不能放在小盤上，將不同初始布局搬至目標
- **猜密碼（Mastermind）**：從預先給定的猜測與黑白回饋，找出唯一符合全部線索的密碼
- **燈泡棋（Akari）**：照亮所有白格、符合數字牆，且燈泡不能彼此照見
- **一人一格（Hitori）**：塗黑部分數字，讓白格行列不重複、黑格不相鄰、白格連通
- **矩形分割（Shikaku）**：將棋盤完整分為矩形，每區恰有一個數字，面積等於線索
- **數字連線（Numberlink）**：成對端點用不交叉路徑連接，完整覆蓋棋盤
- **星星戰棋（Star Battle）**：符合各行、列與區域的星星數，星星不能相鄰，包括斜角

數獨、燈泡棋、一人一格、矩形分割、數字連線與星星戰棋會重新搜尋並計數解，逐關確認唯一解。猜密碼對已給定的初始回饋線索窮舉所有密碼。踩地雷的免猜證明從公開線索出發逐步驗證，不把查詢隱藏地雷答案當成推理。十五數字拼圖與漢諾塔保存完整合法移動證明；只有經過完整最短路搜尋的數字才標為最短步數。

所有新作提供選關、重開、撤銷、提示與本機進度。驗證針對初始關卡的規則和可解性；解答預覽與玩家完成紀錄分開處理。關卡生成程式、證明資料、規則邊界與控制器測試隨原始碼提供。

`node verify-classics.cjs` 重跑本批 500 關驗證、目前全部大廳入口、資產引用與大廳操作測試，產生 `classics-verification-report.json`。不同遊戲的獨立驗證與證明定義，見各遊戲資料夾的 README。模擬 DOM 流程測試不等同實際瀏覽器視覺驗收。

每款遊戲均有玩法說明、重開機制及返回大廳連結。個人最佳紀錄儲存於瀏覽器本機；停用儲存時仍可遊玩。

## 本機預覽

在儲存庫根目錄執行：

```sh
python3 -m http.server 8080
```

開啟 http://localhost:8080 。也可直接打開 `index.html`。

## 檔案

- `index.html`：首頁架構、導覽與區塊
- `styles.css`：響應式版面、CSS 插畫、鍵盤焦點與減少動態效果設定
- `app.js`：遊戲資料、卡片呈現、分類篩選、搜尋與空狀態
- `favicon.svg`：站台圖示
- `games/*.html`：六十七款遊戲入口；原有十二款為單頁，新接龍遊戲搭配同名資料夾中的規則引擎與牌局資料

## 新增遊戲

1. 在 `app.js` 的 `games` 陣列新增資料：

```js
{
  id: 'my-game',
  title: '我的遊戲',
  category: 'puzzle', // puzzle、strategy、casual、cards、board、logic、classic、collection 或 tabletop
  description: '一段簡短介紹。',
  note: '邏輯 × 挑戰',
  art: 'tiles', // tiles、maze、blocks、memory、planet、target
  color: '#c5b3f5',
  background: '#302b48',
  word: 'MY GAME',
  status: 'soon',
  url: ''
}
```

2. 遊戲完成後，放入 `games/my-game/index.html`（或 `games/my-game.html`）。
3. 將 `status` 設成 `'ready'`，`url` 設成 `'./games/my-game/index.html'`。卡片會自動顯示「開始遊戲」。只接受本站 `./games/` 下、英數字／底線／連字號命名的相對路徑，避免錯誤或不安全網址。
4. 更新遊戲內容時，更新 `GAME_BUILD`，首頁產生的遊戲連結會附加版本參數；原本不帶參數的直接網址仍可使用。若更新 `app.js` 或 `styles.css`，也更新 `index.html` 中對應的資產版本。
5. 加入新類型時，同時更新 `categoryNames` 與 `index.html` 篩選按鈕；插畫可在 `artMarkup` 與 CSS 擴充。

遊戲數量會自動更新；分類與搜尋可以交叉使用。搜尋不到時可一鍵重設。所有導覽都能用鍵盤操作；未完成遊戲不會提供假的啟動連結。

## 多人棋桌 · 十款人類與 AI 對戰

全站現有 **67 款遊戲、2,000 關益智挑戰、250 副接龍牌局**，新增十款可反覆對弈的棋類。每款支援 **同一裝置輪流多人遊玩**與 **人類對 AI**，可選 **簡單、普通、困難**。AI 依遊戲使用不同搜尋深度或評估策略；困難代表較深入的有限搜尋，並不宣稱完美或無敵。

- 黑白棋（Reversi）：夾子翻色、無合法步時跳過、雙方皆無步時結算
- 五子棋（Gomoku）：15 × 15 自由規則，連續五枚或以上獲勝
- 四子棋（Connect Four）：7 欄 × 6 列重力落子，任一方向連四
- 西洋跳棋（Checkers）：8 × 8 對弈，強制吃子、連跳、升王
- 中國跳棋（Chinese Checkers）：星形棋盤，以步行或連跳將棋子送進對面營地
- 飛行棋（Aeroplane Chess）：擲骰競速，起飛、追趕與精準進入終點
- 播棋（Kalah）：逐穴播種，己方倉庫落末子可再走，含捕獲與終局清盤
- 九子棋（Nine Men’s Morris）：放子、走子、成磨吃子與三子飛行
- 步步為營（Quoridor）：移動與築牆，任何牆都須保留雙方抵達終點的路徑
- 四連異形棋（Quarto）：選子交給對手落盤，四枚共同特徵連成一線即勝

各遊戲的規則變體、AI 策略與測試指令，見同名資料夾 README。每款有獨立本機存檔，提供撤銷與重新開始；重設、切換模式及讀取存檔會取消過時的 AI 回合。此批是對戰遊戲，不使用預設關卡數量。

`node verify-tabletop.cjs` 重跑十款規則、三難度 AI 合法性、戰術局面、自我對弈與控制器回歸測試，並檢查既有遊戲資產未被更動。`tabletop-verification-report.json` 記錄完整檢查結果。`tabletop-preservation.json` 保存先前 57 款遊戲共 631 個資產的 SHA-256；測試在隔離副本重建證據，避免改動發布內容。`node verify-static.cjs` 檢查全站 HTML / CSS 的本機資產與導覽路徑。這些是離線引擎／模擬 DOM 測試，實際瀏覽器桌面驗收另行執行。

## 基本檢查

```sh
node --check app.js
node verify-static.cjs
node verify-lobby.cjs
node verify-cards.cjs
node verify-puzzles.cjs
node verify-logic.cjs
node verify-classics.cjs
node verify-collection.cjs
node verify-tabletop.cjs
# 或一次執行所有接龍、棋盤與邏輯推理驗證
node verify-all.cjs
```

`verify-cards.cjs` 需要 Node.js 18+ 與 Python 3。它會執行五款遊戲各 50 副的獨立證明重播、規則邊界測試與入口檔案檢查。各遊戲的生成、求解與個別驗證方式請見 `games/<遊戲>/README.md`。

建議新增內容後，在桌面及手機寬度驗證：全部遊戲、各分類、關鍵字搜尋、無結果重設、鍵盤焦點、遊戲連結與直接重新整理。
