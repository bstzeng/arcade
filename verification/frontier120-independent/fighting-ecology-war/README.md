# Independent fighting, ecology and war audit

Run from the Arcade repository root:

    ARCADE_ROOT="$PWD" bash verification/frontier120-independent/ai-strategy/final-run.sh

If the scripts are saved elsewhere, replace that script path. Output JSON is written beside the scripts. Only the audit output directory is written; production is read-only. Node.js 18+ is sufficient. No package installation, browser, network or publishing is used.

The complete suite checks manifest bindings before and after execution, all 4,500 actual-runtime witnesses with independent terminal predicates and step invariants, 6,000 fighting negative-policy runs, anonymous ecology behavioral diversity, unlabeled war graph diversity, reflected fighting layout diversity, independent alternate plans, all 45 mechanic-specific counterfactuals, AI observation/difficulty behavior, malformed saves, and actual controller callbacks in an explicitly minimal DOM simulation.

A source-binding pass does not establish actual browser layout, mobile touch behavior, or hosted deployment correctness. Proofs show reachability under the declared fixed training/normal policies; they do not claim arbitrary-opponent forced wins, unique solutions, scientific realism, or monotonically better win rates for every hard-AI matchup.

`audit-report.json` is the curated final summary. `source-binding-before.json` and `source-binding-after.json` bind both production and assertion-code bytes. Individual `*-report.json` files contain technical results. Initial defect probes, old reports and logs are intentionally not part of the release evidence allowlist.
